# Content Calendar — StudyMate (target: Jan 2026 + onboarding cycle)

Alignment: Pokhara University teaching typically runs in semester blocks with internal
mid-terms (~weeks 5-6) and end-terms (~weeks 13-15); central PU semester exams follow that
window. Publish **before** the exam window the content is meant to serve. This schedule is
"per cohort" cyclical, not one-shot.

## Content pillars
- **P1 — Syllabus + unit notes** (existing 500+ chapter pages): keep evergreen, deepen with
  a 2-3 sentence answer per chapter once SSR lands.
- **P2 — "Old/asked questions" per subject** (high-conversion exam intent): one page per
  subject → curated past questions by chapter, mapped to syllabus units. Feed FAQ schema.
- **P3 — College pages** (13 PU-affiliated colleges): program info + exam-time tables +
  links to its subjects. Own the "notes for X college" query.
- **P4 — Exam prep hubs** (/pu-exam, /pu-exam-grading, NEC/license section): rules, grading,
  model papers. Authority layer for GEO ("what does PU exam grading look like").

## Cadence (assume one active cohort = one semester)
| Week | Pillar | Action |
|---|---|---|
| Pre-term (cohort start) | P1 | Ship subject hubs for the active semester; register chapters SSR'd |
| Weeks 2-4 | P1 + P3 | Fill chapter pages; lay college pages for that semester's colleges |
| Weeks 5-6 (mid-terms) | P2 | Publish mid-term "asked questions" for the 8 active subjects |
| Weeks 7-10 | P3 + P4 | College pages polish; /pu-exam + grading refresh |
| Weeks 11-16 (end-terms) | P2 | End-term asked-questions per subject; FAQ blocks go live |
| Holiday window | P4 | NEC/license section; app-listing refresh; llms.txt + GEO refresh |

Steady state: **2 chapters + 1 question page per week**, alternating subjects across the
active semester; every chapter links to its subject hub and college set.

## GEO/answer quota (every publish)
- Each chapter page: ≥1 directly quotable definition + 1 "difference/why" sentence.
- Each asked-question page: question in H2/H3, crisp answer ≤50 words, exact language the
  student uses ("what is a truth table"), FAQ schema applied.
- Keep answers self-contained (files/AI don't read sibling pages).

## App-popularity tie-in
- Mention "free in StudyMate app (Google Play)" only once per page footer — the human + AI
  value is the page itself; the app CTA is secondary.
- Exam-season push on socials points to asked-question pages, not the app link alone.
