Pokhara University BE Computer Engineering semester 3 tutorial for Database Management System (course code CMP 222) with syllabus, key topics, concepts, and 5 practice questions.

Introduction

Database Management System in Semester 3 is a core subject where students move from file-based thinking to structured, scalable, and secure data management design. The course in Pokhara University BE Computer Engineering combines conceptual modeling, relational schema design, SQL querying, integrity enforcement, transaction processing, and recovery mechanisms. It also introduces modern trends such as NoSQL and blockchain-oriented data systems, making the syllabus aligned with both classical foundations and current industry direction.

The early units focus on database purpose, architecture, ER modeling, relational structure, and algebra. These topics help students understand how to map real application entities into consistent schema design. SQL is then covered in practical depth including DDL, DML, joins, nested queries, views, and stored procedures. Unit 4 on relational design and normalization is especially important because it teaches how to reduce redundancy and update anomalies while preserving data integrity and query efficiency.

The later units handle security, query optimization, file/index structures, transaction concurrency control, and crash recovery. These are the topics that distinguish academic query writing from production-level database engineering. If students practice schema design, query plans, normalization steps, and transaction schedules regularly, DBMS becomes one of the most practical and high-scoring subjects in Semester 3.

What you will learn

  • Differentiate file systems and DBMS architecture with data abstraction levels.
  • Design ER diagrams and map them into relational schema correctly.
  • Write SQL DDL and DML queries including joins, subqueries, and views.
  • Apply integrity constraints, triggers, and normalization up to BCNF.
  • Explain database security controls such as authorization and access control.
  • Interpret query processing, cost estimation, and optimization fundamentals.
  • Use transaction and serializability concepts with concurrency protocols.
  • Explain crash recovery basics and emerging systems like NoSQL and distributed ledgers.

Syllabus Overview

Unit 1: Introduction [4 hrs]

  • DBMS purpose, applications, and DBMS vs file system comparison.
  • View of data and abstraction levels: physical, logical, and view.
  • Data independence, instances, and schemas.
  • Database languages: DDL, DML, and DCL.
  • Database architecture: system architecture and two-tier/three-tier application architecture.

Unit 2: ER and Relational Model [8 hours]

  • ER model foundations: entity sets, attributes, values, and relationship sets.
  • Participation, roles, descriptive attributes, degree, and mapping cardinalities.
  • Attribute types: simple, composite, single-valued, multivalued, derived.
  • ER diagram, specialization, generalization, and aggregation.
  • Keys: super key, candidate key, primary key; strong and weak entities.
  • Introduction to relational model and reduction of ER to relational schema.
  • Relational schema structure and relational algebra basics.

Unit 3: Structured Query Language [5 hours]

  • SQL overview with DDL and DML categories.
  • Basic query structure, rename, string operations, attribute specification, where and order by.
  • Set operations, null values, and aggregate functions.
  • Nested queries and join expressions (natural, conditional, and outer joins).
  • Database modification: insert, update, delete.
  • Views and stored procedures.

Unit 4: Relational Database Design [6 hrs]

  • Integrity constraints: domain, entity, referential, assertions, and triggers.
  • Features of good relational design.
  • Functional dependencies and Armstrong axioms.
  • Closure of FD sets and closure of attribute sets.
  • Normalization: 1NF, 2NF, 3NF, BCNF.
  • Denormalization for performance considerations.

Unit 5: Security [3 hrs]

  • Security and integrity violations.
  • Access control and authorization.
  • Security through views and controlled privileges.

Unit 6: Query Processing and Optimization [5 hrs]

  • Introduction to query processing pipeline.
  • Equivalence of relational expressions.
  • Query cost estimation fundamentals.
  • Query optimization and execution plan selection.

Unit 7: Storage Management and Indexing [3 hrs]

  • File organization: fixed-length and variable-length records.
  • Record organization: heap, sequential, and indexed sequential files.
  • B+ tree index files and hash indices.

Unit 8: Transactions and Concurrency Control [4 hrs]

  • Transaction concepts, model, and state diagram.
  • ACID properties and serializability (conflict and view).
  • SQL standard isolation levels.
  • Concurrency control: lock-based and graph-based protocols.

Unit 9: Crash Recovery [3 hrs]

  • Failure classification.
  • Recovery and atomicity using log records, redo, undo, and checkpoints.
  • Recovery algorithm using logs: rollback and post-crash recovery.
  • Commit optimization and high availability using remote backup systems.

Unit 10: Emerging Trend in Databases [4 hrs]

  • NoSQL databases: characteristics, categories, and advantages.
  • Object-oriented databases and ORM basics.
  • Distributed databases overview.
  • Distributed ledger technology: blockchain, cryptocurrency, and core blockchain properties.

Important Topics

  • ER to relational mapping and key identification.
  • Relational algebra expression writing.
  • SQL joins, nested queries, and view design.
  • Functional dependency closure and candidate key derivation.
  • Normalization to BCNF and denormalization trade-offs.
  • Authorization, privileges, and security through views.
  • Query plan cost reasoning and optimization strategies.
  • Index design choice: B+ tree vs hashing.
  • Serializability and lock-based concurrency control.
  • Log-based recovery and checkpoint handling.

Practice Questions

  1. Design an ER diagram for a real system and convert it into relational schema with keys.
  2. Write SQL queries covering joins, aggregates, nested queries, and update operations.
  3. Normalize a relation to 3NF/BCNF and justify each decomposition step.
  4. Implement integrity constraints, trigger, and view for a sample database.
  5. Explain query optimization using expression equivalence and cost estimation ideas.
  6. Compare heap, sequential, indexed sequential files, and B+ tree indexing.
  7. Test serializability of a schedule and propose lock-based control.
  8. Show redo/undo-based recovery flow for a crash scenario using log records.
