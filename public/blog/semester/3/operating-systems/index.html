Introduction

Operating Systems in Semester 3 introduces the core mechanisms that allow software to use hardware resources safely and efficiently. In Pokhara University BE Computer Engineering, this subject covers process management, synchronization, CPU scheduling, memory management, kernel structure, I/O handling, file systems, and modern OS trends. The course is both conceptual and practical, so students are expected to understand theory and also simulate key algorithms.

The process and thread unit is one of the central parts of this syllabus. It explains concurrent execution, critical section problems, IPC models, and scheduling policies across batch, interactive, and real-time contexts. These ideas are essential for understanding how programs behave under load and why resource allocation decisions affect throughput, response time, and fairness. Memory management then extends the same reasoning to storage hierarchy, paging, segmentation, virtual memory, and replacement algorithms.

Later units connect core abstractions to system-level operations: kernel behavior, interrupt-driven I/O, deadlock handling, file organization, access control, and contemporary operating system directions such as distributed, cloud, mobile, and real-time systems. Students who practice algorithm simulation and scenario-based reasoning regularly usually gain strong confidence in both exams and real systems understanding.

What you will learn

  • Explain OS roles, architecture styles, and evolution.
  • Model processes and threads with lifecycle and scheduling behavior.
  • Apply IPC and synchronization techniques to avoid race conditions.
  • Compare CPU scheduling algorithms using performance criteria.
  • Analyze memory allocation, paging, virtual memory, and page replacement.
  • Explain kernel types, mode switching, and basic kernel services.
  • Interpret I/O hardware-software principles and deadlock strategies.
  • Describe file-system implementation and trends in modern operating systems.

Syllabus Overview

Unit 1: Introduction [4 hrs]

  • Concept and functions of operating systems.
  • Processes, files, system calls, and shell basics.
  • OS structures: monolithic, layered, virtual machine, client-server, microkernel, and exokernel.
  • Types and evolution of operating systems.

Unit 2: Processes and Threads [10 hours]

  • Process definition, states, transition diagram, and PCB.
  • Concurrent and parallel processes with IPC and synchronization.
  • Race condition, critical region, mutual exclusion, and serializability concepts.
  • Mutual exclusion techniques: disabling interrupt, lock variable, strict alternation, Dekker, Peterson, TSL, sleep/wakeup.
  • Synchronization tools: semaphore, monitor, bounded buffer, and message passing.
  • Classical IPC problems: dining philosophers, readers-writers, sleeping barber.
  • Scheduling concepts and criteria for preemptive/non-preemptive, batch, interactive, and real-time systems.
  • Algorithms: FCFS, SJF, Round Robin, shortest process next, shortest remaining time next, priority/fair share/lottery.
  • Thread models: many-to-one, one-to-one, many-to-many, user space vs kernel space threads.
  • Difference between process and thread.

Unit 3: Memory Management [10 hours]

  • Storage organization, memory hierarchy, and allocation models.
  • Contiguous vs non-contiguous allocation; logical vs physical memory.
  • Fragmentation, relocation, protection, and swapping-based management.
  • Contiguous memory allocation and internal/external fragmentation.
  • Paging and page-table structures: hierarchical, hashed, inverted, shared.
  • Virtual memory, TLB, demand paging, and thrashing.
  • Page replacement: FIFO, NRU, optimal, second chance, LRU, clock, working set, WS clock.
  • Segmentation and segmentation with paging.
  • Coalescing and compaction.

Unit 4: Kernel [2 hrs]

  • Kernel introduction and architecture.
  • Types of kernels and their characteristics.
  • Context switching between user and kernel modes.
  • Kernel implementation processes.

Unit 5: Input/Output Management [5 hrs]

  • I/O introduction and interrupt handlers.
  • I/O hardware principles: device, controller, memory-mapped I/O, DMA.
  • I/O software principles: polled vs interrupt-driven I/O, device drivers, device-independent and user-space I/O.
  • Deadlock handling: prevention, avoidance (Banker), detection (resource allocation graph), and recovery.
  • RAID and RAM disk concepts.

Unit 6: File Systems [3 hrs]

  • File organization and file attributes/operations.
  • Blocking, buffering, descriptors, naming, and access methods.
  • Directory management: single-level and hierarchical directories, path names, operations.
  • Protection mechanisms and access control lists.
  • File-system implementation: contiguous, linked-list, and indexed-node allocation.
  • Security and multimedia file considerations.

Unit 7: New Trends in Operating System

  • Concept, characteristics, and role of modern operating systems.
  • Real-time operating systems.
  • Distributed operating systems.
  • Cloud operating systems.
  • Mobile operating systems.
  • Security issues and deployment considerations.
  • Memory wall and bottleneck context in OS design.

Important Topics

  • OS architecture comparison: monolithic vs microkernel styles.
  • Critical section and synchronization problem modeling.
  • Scheduling algorithm performance trade-offs.
  • Page-table organizations and virtual memory translation.
  • Page replacement algorithm behavior under workload change.
  • Kernel mode vs user mode context switching.
  • DMA and interrupt-driven I/O coordination.
  • Deadlock prevention/avoidance/detection workflow.
  • File allocation and directory management strategies.
  • Real-time, distributed, cloud, and mobile OS characteristics.

Practice Questions

  1. Compare monolithic, layered, and microkernel OS structures with use cases.
  2. Analyze a process synchronization problem and design semaphore-based solution.
  3. Compute waiting/turnaround times for multiple scheduling algorithms on same dataset.
  4. Trace page replacement results for FIFO, LRU, and optimal policies.
  5. Explain TLB and demand paging with a page-fault handling sequence.
  6. Design deadlock handling strategy for a resource-allocation scenario using Banker concept.
  7. Differentiate file allocation methods and choose one for given workload.
  8. Summarize design challenges of cloud or mobile operating systems with security considerations.
