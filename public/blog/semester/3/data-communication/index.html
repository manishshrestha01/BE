Introduction

Data Communication in Semester 3 provides the communication-theory and protocol foundation needed for networking, distributed computing, and modern digital systems. The course in Pokhara University BE Computer Engineering explains how data is represented, transmitted, encoded, protected from errors, and transported through layered communication architectures. It combines conceptual networking topics with signal-level and modulation-level understanding, making it both broad and practical.

The syllabus begins with transmission fundamentals, data rate limits, and signal-system basics, then introduces networking models through OSI/TCP-IP layers, LAN/WAN technologies, and protocol stack concepts. Students also study physical transmission media in detail, including guided and unguided channels, propagation behavior, and antenna-linked communication environments.

Later units emphasize impairments, error detection/correction, compression techniques, link-layer control, multiplexing/switching, and digital/analog modulation strategies. These units are highly relevant to real communication systems and help students reason from physical constraints up to protocol behavior. Consistent numerical practice and protocol flow analysis make this subject much easier and more useful in later networking courses.

What you will learn

  • Explain core terminology and evolution of data communication systems.
  • Differentiate parallel/serial transmission and communication modes.
  • Use Nyquist and Shannon concepts for data-rate limit interpretation.
  • Classify signals and systems with basic LTI properties.
  • Interpret OSI/TCP-IP layers, LAN/WAN technologies, and protocol roles.
  • Compare guided and unguided transmission media and propagation choices.
  • Apply error control, compression, framing, and flow-control techniques.
  • Describe coding and modulation schemes including PSK, QAM, PCM, and delta modulation.

Syllabus Overview

Unit 1: Introduction (2 hrs)

  • Evolution of data communication systems.
  • Analog and digital data transmission fundamentals.
  • Basic terminology, standards organizations, and applications.

Unit 2: Data Transmission (3 hrs)

  • Parallel and serial transmission techniques.
  • Synchronous, asynchronous, and isochronous communication.
  • Modes of data transmission and line configuration.
  • Bit rate and baud rate concepts.
  • Data rate limits: Shannon capacity theorem and Nyquist bit-rate criterion.
  • RS-232C interfaces (DTE-DCE and DTE-DTE contexts).

Unit 3: Signals and Systems (6 hrs)

  • Signal classifications: periodic/non-periodic, deterministic/random, energy/power, continuous/discrete-time.
  • Elementary signals: unit step, ramp, impulse, sinusoidal, and signum.
  • Continuous and discrete-time system models.
  • System properties: linearity, causality, stability, static/dynamic behavior, and time invariance.
  • Introduction to LTI systems.

Unit 4: Overview of Data Communication Networking and Protocols (4 hrs)

  • Network types and topology.
  • OSI layers and functions with TCP/IP layering.
  • LAN architecture with LLC/MAC and routing overview.
  • IEEE standards and Ethernet basics (ALOHA and CSMA).
  • WAN technologies: X.25, frame relay, and ATM.

Unit 5: Transmission Media (5 hrs)

  • Electromagnetic spectrum for telecommunication and propagation types.
  • Guided media: twisted pair, coaxial cable, optical fiber.
  • Unguided communication bands and antenna basics.
  • Unguided media: terrestrial microwave, satellite communication, VSAT, and cellular telephony.

Unit 6: Impairments, Error Handling and Compression Techniques (6 hrs)

  • Attenuation, delay distortion, noise, interference, and crosstalk.
  • Error types with detection and correction methods.
  • Data compression techniques.
  • Lossless compression: run length coding, dictionary coding, Huffman coding.
  • Lossy compression: predictive coding and transform coding.

Unit 7: Data Link Control and Protocol (5 hrs)

  • Framing methods.
  • Flow control: stop-and-wait and sliding window.
  • Error control with ARQ variants.
  • HDLC protocol basics.
  • Point-to-point protocol overview.

Unit 8: Multiplexing and Switching (5 hrs)

  • Multiplexing types and applications.
  • Multiplexing vs non-multiplexing comparison.
  • Telephone system hierarchy in analog and digital services.
  • Switching: circuit, packet, and message switching.
  • Private branch exchange basics.

Unit 9: Data Encoding and Modulation (9 hrs)

  • Line coding: unipolar, polar, and bipolar signaling.
  • Digital modulation: ASK, FSK, and PSK.
  • Analog-to-digital conversion: PCM and delta modulation.
  • Analog modulation: AM, FM, and PM.
  • Multilevel modulation: QPSK and QAM.
  • Introduction to modem operation.

Important Topics

  • Nyquist and Shannon limits for channel capacity reasoning.
  • Signal classification and LTI property checks.
  • OSI vs TCP/IP layer mapping.
  • LAN/WAN technologies and protocol placement.
  • Transmission media selection by range, bandwidth, and noise behavior.
  • Error detection/correction with ARQ flow understanding.
  • Framing and sliding-window protocol mechanics.
  • Multiplexing and switching trade-offs.
  • Line coding pattern differences and bandwidth impact.
  • Digital/analog modulation and modem concept linkage.

Practice Questions

  1. Differentiate serial transmission modes and justify suitable use cases.
  2. Solve a channel-capacity problem using Nyquist and Shannon criteria.
  3. Classify given signals and verify selected system properties.
  4. Compare OSI and TCP/IP layers with practical protocol examples.
  5. Select an appropriate transmission medium for three networking scenarios and justify.
  6. Explain framing, stop-and-wait, sliding window, and ARQ with sequence examples.
  7. Compare circuit, packet, and message switching for traffic patterns.
  8. Differentiate line coding and modulation schemes (ASK/FSK/PSK/QAM) with application context.
