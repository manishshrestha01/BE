Pokhara University BE Computer Engineering semester 3 tutorial for Microprocessor and Assembly Language Programming (course code CMP 224) with syllabus, key topics, concepts, and 5 practice questions.

Introduction

Microprocessor and Assembly Language Programming in Semester 3 introduces the hardware-software bridge required for low-level system understanding. The course builds practical knowledge of microprocessor organization, instruction execution, memory and I/O interfacing, and interrupt-driven behavior. In Pokhara University BE Computer Engineering, this subject is a key step for students who will later study embedded systems, computer architecture, and hardware-near optimization.

The syllabus starts with basic microprocessor evolution, bus organization, and microcomputer architecture, then moves into the architectural and programming details of Intel 8085 and 8086 families. Students learn instruction classes, addressing modes, timing cycles, and assembly-language program development with loops, conditions, stack usage, procedures, and macros. These topics are reinforced through practical programming and interface design tasks.

Advanced units focus on bus structures, memory hierarchy, address decoding, programmable peripheral interfaces, serial communication interfaces, DMA controllers, and interrupt handling flow. By studying this sequence carefully, students understand not only what instructions do, but how data physically moves across system components. Consistent ALP practice and timing-level reasoning make this course highly valuable for both exams and real device-level work.

What you will learn

  • Explain evolution and system-level organization of microprocessor-based computers.
  • Describe 8085 and 8086 architectural blocks and instruction-cycle behavior.
  • Use addressing modes and instruction classes in ALP design.
  • Write assembly programs using loops, conditions, stack, procedures, and macros.
  • Differentiate memory-mapped and I/O-mapped interfacing approaches.
  • Design address-decoding logic for memory and peripheral interfacing.
  • Explain serial/parallel interfaces, DMA basics, and peripheral controller roles.
  • Analyze interrupt processing sequence and programmable interrupt controller behavior.

Syllabus Overview

Unit 1: Introduction to Microprocessor (3 hrs)

  • Historical evolution of Intel series microprocessors.
  • Bus organization in microprocessor-based systems.
  • Microcontroller concept and applications.
  • Microcomputer concepts with Von Neumann and Harvard architecture.
  • Fetch-decode-execute cycle fundamentals.

Unit 2: Architectural Details and Programming of 8085 Microprocessor [12 hrs]

  • Internal architecture and key features of 8085.
  • 8085 instruction set and instruction classification.
  • Instruction groups: data transfer, arithmetic, logical, branching, stack, I/O, and machine control.
  • Addressing modes and their types in 8085.
  • Instruction cycle, machine cycle, and T-state.
  • Timing diagrams: opcode fetch, memory read/write, I/O read/write.
  • Assembly language instruction format and simple ALP for arithmetic/logical operations, conditions, and loops.

Unit 3: Architectural Details and Programming of 8086 Microprocessor [10 hrs]

  • 8086 architectural details including BIU and EU.
  • Memory segmentation with segment and offset address concept.
  • 8086 instruction set and instruction classes.
  • Instruction groups including data transfer, arithmetic, logical, branching, string manipulation, and machine control.
  • Addressing modes in 8086.
  • ALP development tools: editor, assembler, linker, debugger, locator, emulator.
  • Assembler directives and DOS interrupt functions (keyboard/display services).
  • Programs for arithmetic, logical, string I/O, loops, stack procedures, and macro-based design.

Unit 4: Bus Structure, Memory, I/O and Interfacing [12 hrs]

  • Bus structures: synchronous and asynchronous buses.
  • Memory device classification and memory hierarchy.
  • Interfacing memory and I/O with address decoding techniques.
  • Unique/non-unique address decoding, I/O mapped and memory mapped I/O.
  • I/O and memory address decoding in 8085.
  • Parallel interface modes and Intel 8255 PPI architecture.
  • Serial interface: synchronous/asynchronous transmission and 8251 USART.
  • DMA concepts and Intel 8237A DMA controller overview.

Unit 5: Interrupt Operation [8 hrs]

  • Interrupt concept, sources, and classification.
  • Interrupt processing sequence in 8085/8086.
  • Interrupt instructions, pins, priorities, and service procedures.
  • Interrupt vector table and multiple interrupt handling.
  • Polled vs vectored interrupts.
  • Programmable Interrupt Controller (Intel 8259) and architecture.

Important Topics

  • Fetch-decode-execute cycle and bus-level signal interpretation.
  • 8085 instruction classification and addressing modes.
  • 8085 timing diagrams and machine-cycle analysis.
  • 8086 BIU-EU split and segmentation addressing.
  • Assembler directives, macros, and procedure design patterns.
  • Address decoding for memory and I/O interfacing.
  • 8255 PPI and 8251 USART role in interface design.
  • DMA flow and 8237A controller basics.
  • Interrupt priorities, vector table handling, and ISR flow.
  • 8259 PIC usage in multiple-interrupt environments.

Practice Questions

  1. Draw and explain a microprocessor-based system block diagram with bus lines.
  2. Classify 8085 instructions with examples and write one ALP using loops and conditions.
  3. Explain machine cycle and T-state, then sketch opcode fetch and memory read timing.
  4. Differentiate 8085 and 8086 architecture with BIU/EU and segmentation focus.
  5. Write an 8086 ALP using stack procedures or macro technique for a small task.
  6. Design address decoding logic for interfacing memory and an I/O device with 8085.
  7. Compare memory-mapped I/O and I/O-mapped I/O with practical implications.
  8. Explain interrupt processing sequence and illustrate use of 8259 PIC in multi-interrupt setup.
