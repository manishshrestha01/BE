Introduction

Computer Graphics in Semester 3 introduces how graphical objects and scenes are represented, transformed, and rendered on digital display systems. The course in Pokhara University BE Computer Engineering combines mathematical modeling, algorithmic construction, and practical programming so students can build visual outputs instead of only studying theory. It starts with graphics hardware and system overview, then moves into scan conversion algorithms that generate fundamental primitives such as lines, circles, and filled polygons.

The core computational part covers two-dimensional and three-dimensional transformations, viewing pipelines, clipping algorithms, and projection methods. These topics help students understand how a world-coordinate object is mapped to a screen with proper orientation, scaling, and visibility constraints. The syllabus then extends into visual realism through hidden-surface removal, illumination models, shading methods, and color models, which are crucial for rendering believable scenes.

The final units discuss graphical standards for portability and introduce OpenGL architecture and library-based programming. With steady practice in algorithm implementation and transformation problems, students develop strong foundational skills for graphics programming, simulation, gaming, and visualization-oriented engineering applications.

What you will learn

  • Explain graphics system components including display and input hardware.
  • Implement scan conversion for line, circle, ellipse, and polygon filling.
  • Apply 2D geometric transformations and matrix composition correctly.
  • Use viewing pipeline and clipping methods for window-to-viewport mapping.
  • Apply 3D transformations, projection types, and 3D clipping basics.
  • Compare hidden-surface removal and shading approaches for realism.
  • Understand graphics standards and portable graphics software concepts.
  • Build basic graphical output using OpenGL libraries and transformations.

Syllabus Overview

Unit 1: Overview of Computer Graphics and Graphics Systems (7 hrs)

  • Introduction, applications, and recent trends in computer graphics.
  • Interactive input devices and display devices.
  • Color monitors, hard-copy devices, raster and random scan systems.
  • Video controller, DAC usage, and frame-buffer organization.
  • Graphics software and modern graphics hardware (GPU).

Unit 2: Scan Conversion Algorithms (7 hrs)

  • Scan conversion fundamentals.
  • Line drawing algorithms: DDA and Bresenham.
  • Circle generation and ellipse generation algorithms.
  • Filled area primitives and polygon fill routines.
  • Scan-line polygon fill, boundary fill, and flood fill algorithms.

Unit 3: Two Dimensional Geometric Transformations and Viewing (8 hrs)

  • 2D transformations: translation, rotation, scaling, shearing, reflection.
  • Matrix representation of transformations and homogeneous coordinates.
  • Composite transformations for combined operations.
  • Windowing concepts and 2D viewing pipeline.
  • Window-to-viewport transformation.
  • Clipping algorithms: Cohen-Sutherland line clipping and Sutherland-Hodgman polygon clipping.

Unit 4: Graphics in Three Dimensions (8 hrs)

  • 3D coordinate systems and 3D transformations.
  • 3D translation, rotation, scaling, and reflection.
  • 3D representations: polygon surfaces, cubic spline and Bezier curve.
  • Non-planar surface representation using Bezier surface and fractal approach.
  • 3D viewing transformation pipeline.
  • Projection methods: parallel and perspective projection.
  • Clipping in three dimensions.

Unit 5: Visual Realism (7 hrs)

  • Hidden surface and hidden surface removal approaches.
  • Back-face detection, depth buffer, A-buffer, scan-line, and depth sorting methods.
  • Illumination theory and lighting models.
  • Ambient, diffuse, and specular reflection (Phong model).
  • Surface shading methods: flat, Gouraud, Phong, and fast Phong shading.
  • Color models: RGB and CMYK.

Unit 6: Graphical Standards (4 hrs)

  • Need for machine-independent graphical languages.
  • Graphical standards: PHIGS and GKS.
  • Graphics software standards and language bindings.
  • Overview of graphics file formats.
  • Visualization of data sets.

Unit 7: Introduction to OpenGL (4 hrs)

  • Overview and basic architecture of OpenGL.
  • GL-related libraries and setup context.
  • Drawing basic output primitives and polygons.
  • Callback functions and input handling.
  • Basic transformations, projection, and lighting in OpenGL.

Important Topics

  • Raster vs random scan architecture differences.
  • DDA and Bresenham algorithm step-by-step comparison.
  • Polygon filling and boundary/flood-fill logic.
  • Homogeneous coordinate matrix composition in 2D.
  • Window-to-viewport mapping and clipping pipelines.
  • 3D transformation and projection matrix reasoning.
  • Hidden-surface removal algorithm selection criteria.
  • Phong reflection and shading model differences.
  • PHIGS/GKS role in software portability.
  • OpenGL primitive drawing and transformation workflow.

Practice Questions

  1. Compare raster and random scan systems with frame-buffer implications.
  2. Implement DDA and Bresenham line drawing and compare generated pixel steps.
  3. Apply composite 2D transformations for fixed-point scaling and pivot rotation.
  4. Clip line and polygon primitives against a window using standard algorithms.
  5. Construct a Bezier curve from control points and explain geometric behavior.
  6. Explain hidden-surface removal using depth-buffer and back-face techniques.
  7. Differentiate flat, Gouraud, and Phong shading for the same polygon model.
  8. Create a small OpenGL program that draws primitives and applies basic transforms.
