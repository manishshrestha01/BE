Introduction

Computer Workshop is a hands-on practical course in Semester 1 designed to build operational confidence with real computer systems. In Pokhara University BE Computer Engineering, this course complements theoretical subjects by training students to identify hardware components, assemble systems, install operating systems, configure networks, and troubleshoot common faults. Instead of only learning conceptual definitions, students directly work with motherboards, storage, memory, power supplies, peripherals, and software tools. This practical base is important because strong system-level handling skills reduce fear of hardware/software setup tasks in later labs and projects.

The course begins with desktop/workstation components and assembly safety, then moves into laptop assembly and OS installation workflows. Students learn BIOS settings, partitioning, installation of Linux/Windows, account management, and peripheral setup. Networking units cover basic wired and wireless setup, cable types, and fundamental configuration awareness. Software installation, firmware updates, and virus scanning are also included so students can maintain system reliability rather than only perform one-time setup.

The final units focus on server basics, sharing, file transfer awareness, and troubleshooting practices. This gives students an industry-relevant mindset: diagnose first, isolate the issue, apply tools, and verify results. When students treat each lab as a repeatable checklist instead of a one-time task, they develop strong technical discipline. This guide summarizes the unit-wise practical flow and provides high-value revision points and practice questions aligned with the official workshop syllabus.

What you will learn

  • Identify major desktop and laptop hardware components and connectors.
  • Perform safe assembly/disassembly steps for desktop and laptop systems.
  • Configure BIOS/boot settings and install Windows/Linux environments.
  • Manage partitioning, user accounts, and peripheral installation workflows.
  • Set up basic wired/wireless networking and understand media/connectors.
  • Install/update application and utility software with basic security hygiene.
  • Understand basic server concepts and file/device sharing flow.
  • Use troubleshooting commands and tools for hardware/software fault isolation.

Syllabus Overview

Unit I: Introduction to Desktop/Workstation Assembly

  • Demonstration of processor, motherboard, memory, storage, and I/O devices.
  • Demonstration of SMPS, internal cabling, and ports.

Unit II: Assembling Desktop Computer

  • Assembly sequence and safety precautions.
  • Setting motherboard, memory, hard disk, processor, optical drive, and PSU.

Unit III: Assembling Laptop

  • Laptop assembly/disassembly steps and precautions.
  • Laptop board, memory, storage, processor, and module-level component handling.

Unit IV: Laptop/Desktop OS Installation

  • BIOS setting, firmware types, and boot configuration.
  • Disk partitioning and OS installation (Linux/Windows).
  • User account management and device installation (printer/scanner).

Unit V: Networking and Internet Setup

  • Introduction to network topologies and media.
  • Network cabling, connector basics, and wireless AP configuration.

Unit VI: Software Installation

  • Application and utility software installation.
  • Firmware patches/updates and virus scanning workflow.

Unit VII: Server Installation and Backup

  • Server basics and introductory use cases.
  • IP settings and printer/device sharing.
  • Awareness of email, data, domain, and FTP servers.

Unit VIII: Hardware and Software Troubleshooting

  • Basic desktop/laptop repair and preventive maintenance.
  • Replacement awareness of passive components.
  • Software troubleshooting commands and diagnostic utilities.

Important Topics

  • Hardware identification checklist before assembly.
  • Anti-static and component handling precautions.
  • Correct order for motherboard-CPU-RAM-storage installation.
  • BIOS/UEFI boot mode and partitioning decisions.
  • Linux/Windows installation essentials and driver/peripheral setup.
  • Basic wired LAN and wireless AP setup flow.
  • Software install/update hygiene and malware scan workflow.
  • Foundational server concepts and local network sharing setup.
  • Troubleshooting command usage for OS/network checks.
  • Repair-vs-replace decision logic in workshop context.

Practice Questions

  1. Create a step-by-step checklist for assembling a desktop from bare components.
  2. List and explain three critical safety precautions during laptop disassembly.
  3. Write a boot troubleshooting flow when OS installation media is not detected.
  4. Compare BIOS/UEFI and explain their role during OS installation.
  5. Describe a complete setup process for a small wired + wireless lab network.
  6. Design a maintenance routine for software updates, antivirus scan, and backup.
  7. Explain how you would isolate whether a no-display issue is hardware or software related.
  8. Document a troubleshooting report format suitable for workshop practical submission.
