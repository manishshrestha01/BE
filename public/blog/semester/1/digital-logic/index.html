Introduction

Digital Logic is one of the most important foundation subjects in Semester 1 because it introduces how modern computing hardware represents, processes, and controls information. In Pokhara University BE Computer Engineering, this course starts from number systems and Boolean algebra and then builds into combinational circuits, sequential logic, registers, counters, and memory/ALU concepts. This staged progression mirrors actual digital system design: represent information, simplify logic, implement gates, combine modules, and build larger computing units.

Students who approach Digital Logic only as formula memorization usually struggle in circuit design questions. A better approach is to connect each chapter to a design workflow: define required behavior, write truth table, derive/simplify expression, choose implementation (basic/universal gates), and verify outputs. This method helps in both theory and practical sessions. Units on Karnaugh map simplification, MSI/LSI components, and flip-flop based sequential design are particularly high-weight in exams and should be practiced with repeated hand-solved examples.

The later topics on registers, counters, memory units, and ALU connect directly to computer architecture and microprocessor learning in upcoming semesters. So mastering Digital Logic early gives long-term benefits beyond Semester 1 marks. This guide organizes the syllabus in a practical order and highlights the most exam-relevant areas so you can move from concepts to implementation with confidence.

What you will learn

  • Convert numbers across decimal, binary, octal, and hexadecimal systems accurately.
  • Apply complements and binary coding schemes to represent data correctly.
  • Use Boolean algebra laws and DeMorgan principles for expression simplification.
  • Implement logic functions using basic gates and universal NAND/NOR gates.
  • Design and analyze combinational circuits like adders, subtractors, and parity units.
  • Work with MSI/LSI blocks such as multiplexers, decoders, comparators, ROM, and PLA.
  • Design sequential circuits using flip-flops, state tables, and state diagrams.
  • Analyze registers, counters, memory units, and basic ALU structure.

Syllabus Overview

Unit I: Introduction (2 hrs)

  • Analog vs digital signal and systems.
  • Numerical representation and digital number systems.

Unit II: Number Systems and Codes (6 hrs)

  • Decimal, binary, octal, and hexadecimal systems.
  • Number conversion and complement methods.
  • Subtraction using complements.
  • Weighted and non-weighted codes, alphanumeric/instruction codes.

Unit III: Boolean Algebra and Logic Gates (4 hrs)

  • Boolean properties, postulates, and theorems.
  • Gate truth tables and Boolean function representation.
  • Duality, complement, gate implementation, NAND/NOR universality.

Unit IV: Simplification of Boolean Function (5 hrs)

  • Canonical/standard forms and K-map up to 5 variables.
  • Minimum realization with don't-care conditions.
  • SOP/POS simplification using K-map.

Unit V: Combinational Circuit (4 hrs)

  • Design and analysis procedure for combinational logic.
  • Adder, subtractor, and code conversion circuits.
  • NAND/NOR and multilevel implementations.
  • Parity generator/checker design.

Unit VI: MSI and LSI Design (6 hrs)

  • Integration technology basics.
  • Parallel adder/subtractor, BCD adder, comparator.
  • MUX/DEMUX, encoder/decoder, ROM, PLA.

Unit VII: Sequential Circuits (6 hrs)

  • Synchronous vs asynchronous logic.
  • Latch and flip-flop types, triggering, excitation/characteristic relations.
  • State diagram/table, state reduction, and clocked circuit design.
  • Master-slave flip-flops.

Unit VIII: Registers and Counters (6 hrs)

  • Register and shift register types.
  • Synchronous and asynchronous counters, BCD/mod counters.
  • Ring counter and output hazard concepts.

Unit IX: Memory Unit and ALU (6 hrs)

  • Random access memory fundamentals.
  • Arithmetic logic unit design basics.
  • Accumulator, shifter, status register, and processor unit overview.

Important Topics

  • Number conversion speed methods and complement arithmetic.
  • Boolean theorem applications and duality principle.
  • NAND/NOR universal implementation technique.
  • K-map simplification with don't-care handling.
  • Adder/subtractor and code converter design.
  • MUX/DEMUX and encoder/decoder problem patterns.
  • Flip-flop excitation tables and state-transition design.
  • Synchronous vs ripple counter design trade-offs.
  • Register operations and hazard/race awareness.
  • Memory-ALU-processor unit relationship in digital systems.

Practice Questions

  1. Convert a mixed set of numbers between decimal, binary, octal, and hexadecimal and verify using complements.
  2. Simplify a 4-variable Boolean function using K-map in both SOP and POS forms.
  3. Implement a given Boolean function using only NAND gates and then only NOR gates.
  4. Design a full adder using basic gates and explain how to scale it to a parallel adder.
  5. Design a 4:1 multiplexer realization for a target logic function and verify truth table.
  6. Derive excitation requirements to convert one flip-flop type into another.
  7. Design a mod-10 asynchronous counter and explain possible output hazards.
  8. Draw a simple ALU block with accumulator and explain data flow for one arithmetic and one logic operation.
