Introduction

Programming in C is the first core coding subject in Semester 1 and serves as the base for algorithmic thinking in later software courses. In Pokhara University BE Computer Engineering, this course is designed around structured programming and disciplined problem solving rather than only syntax memorization. Students are expected to follow a complete development cycle: understand the problem, design algorithm and flowchart, write C code, compile/run, test/debug, and document clearly. This process-driven approach is what makes the subject academically and professionally important.

The syllabus starts with programming language generations and software fundamentals, then moves into C-specific constructs such as data types, operators, control structures, arrays, strings, functions, pointers, structures, unions, and file handling. Each unit adds one layer of complexity and reuses previous skills. For example, arrays and functions combine into modular programming; pointers extend this into dynamic memory and efficient parameter passing; structures and file operations connect programs to realistic data representation and persistence needs.

Students who practice only final code output often struggle in exams that test logic, tracing, and design rationale. A stronger method is to practice dry-run tables, trace variable state changes, and explain why a specific structure (loop, function, pointer, structure, file mode) is used. If you follow that pattern, Programming in C becomes a strong scoring subject and prepares you directly for Data Structure, OOP, Operating Systems, and systems programming topics in later semesters. This guide follows the official unit flow and highlights high-value concepts and practice patterns.

What you will learn

  • Explain programming language generations and structured programming foundations.
  • Use C language syntax, data types, operators, and formatted I/O correctly.
  • Implement conditional and looping control structures for algorithmic logic.
  • Work with one-dimensional/multi-dimensional arrays and string handling functions.
  • Design modular programs using functions, recursion, and parameter passing.
  • Use pointers for memory access, array-function integration, and dynamic allocation.
  • Model heterogeneous data using structures, unions, and self-referential forms.
  • Store and retrieve persistent data using file pointers and C file-handling modes.

Syllabus Overview

Unit 1: Programming Languages and Problem Solving (6 hrs)

  • Machine/assembly/high-level language generations and comparison.
  • Software types and structured programming principles.
  • Problem-solving cycle: analysis, algorithm, flowchart, coding, testing, documentation.

Unit 2: Introduction to C (6 hrs)

  • History, features, and strengths of C language.
  • C as middle-level and system programming language.
  • Character set, keywords, identifiers, data types, constants, variables.
  • Formatted input-output functions and C operators.

Unit 3: Control Structures (6 hrs)

  • Sequential, branching, and looping statements.
  • if, if-else, nested if, ladder, switch.
  • for, while, do-while, nested loops.
  • break, continue, and goto usage.

Unit 4: Arrays and Strings (6 hrs)

  • One-dimensional and multidimensional arrays.
  • Array initialization and element access.
  • Character arrays and string concepts.
  • Core string-related functions.

Unit 5: Functions (6 hrs)

  • Function importance, declaration, prototype, and invocation.
  • Call by value vs call by reference.
  • Recursive function concepts and array passing.
  • Scope: local/global/formal parameters and storage classes.
  • Preprocessor directives, header files, and macros.

Unit 6: Pointers (6 hrs)

  • Pointer basics, operators, and arithmetic.
  • Pointers with arrays and functions.
  • Returning multiple values using pointers.
  • Double indirection and dynamic memory allocation.

Unit 7: Structure and Union (5 hrs)

  • Structure definition and nested structure.
  • Array of structures and pointers with structures.
  • Union and self-referential structure usage.

Unit 8: Files and File Handling (4 hrs)

  • FILE pointer and open modes (read/write/append).
  • File handling functions and operations in different modes.
  • Permanent storage workflow in C programs.

Important Topics

  • Algorithm and flowchart design before coding.
  • Data types, operators, and precedence in expression evaluation.
  • Branching and looping trace-table based debugging.
  • Array traversal and string manipulation patterns.
  • Function prototype correctness and recursion design.
  • Call-by-value vs call-by-reference behavior.
  • Pointer arithmetic and dynamic memory management.
  • Structure/union representation and use-case difference.
  • File modes, file pointer safety, and I/O error checks.
  • Program testing, debugging, and clean documentation style.

Practice Questions

  1. Design algorithm and flowchart to solve matrix multiplication, then write equivalent C code.
  2. Write a C program using branching and loops to validate prime numbers within a range.
  3. Create a program to process a one-dimensional array and pass it to a function for statistics computation.
  4. Implement recursive functions for factorial and Fibonacci, and compare with iterative approach.
  5. Write a program that swaps values and returns multiple outputs from a function using pointers.
  6. Build a structure-based student record system and explain where union could be preferred.
  7. Use dynamic memory allocation to create and process a variable-length integer list.
  8. Create a file handling program that writes, appends, and reads records with proper error handling.
