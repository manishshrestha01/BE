Introduction

Software Engineering in Semester 5 gives students a complete lifecycle view of how high-quality software is planned, developed, validated, and maintained. In Pokhara University BE Computer Engineering, the course combines technical development activities with managerial controls required for medium-to-large software projects. It teaches not only coding-centric concepts but also process discipline, risk management, quality assurance, and configuration control.

The syllabus starts with software and project-management foundations, process models, and agile methods. It then moves through requirements engineering, architecture/design principles, and testing/maintenance workflows. This progression mirrors real project execution and helps students understand how each phase affects cost, quality, and delivery reliability.

The final chapters focus on process quality, standards compliance, configuration management, and advanced trends such as reuse, cloud-based engineering, and AI-assisted software development. With consistent case-tool practice and lifecycle documentation exercises, students can build strong software engineering maturity for internships and professional roles.

What you will learn

  • Explain software engineering principles and project-management fundamentals.
  • Compare SDLC models and choose process models by project context.
  • Perform requirements elicitation, modeling, and validation activities.
  • Design software architecture and components using structured and OO approaches.
  • Create test strategies and apply validation/verification techniques.
  • Understand software quality assurance standards and process improvement.
  • Manage software configuration items and version/release workflows.
  • Interpret modern trends including software reuse, cloud engineering, and AI in software engineering.

Syllabus Overview

Chapter 1: Software Engineering and Project Management (7 hrs)

  • Nature and characteristics of software.
  • Software vs system engineering; software crisis and myths.
  • Four Ps of software project management.
  • Process/project metrics and software measurement concepts.
  • Project estimation and empirical estimation models.
  • Software risk handling: identification, mitigation, monitoring, management.
  • Software engineering ethics and professional practice.

Chapter 2: Software Process Models and Agility (5 hrs)

  • Software development lifecycle (SDLC).
  • Waterfall, incremental, prototyping, iterative, spiral, RAD, aspect-oriented approaches.
  • Agile development, extreme programming, Scrum.
  • Agile project management and scaling agile methods.
  • Pros/cons and applicability of process models.

Chapter 3: Requirements Engineering and Principles (7 hrs)

  • Types of requirements and modeling principles.
  • Domain analysis and system models: context, behavioral, and data models.
  • Requirements engineering process: feasibility, elicitation, analysis, modeling, specification, validation.
  • Object-oriented analysis.

Chapter 4: Software Design, Architecture and Principles (7 hrs)

  • Design modeling principles and design process.
  • Architectural styles: layered, repository, client-server, pipe-and-filter.
  • Interface, component, and database design.
  • Design patterns and security by design.
  • Object-oriented design and embedded system design context.

Chapter 5: Testing Techniques and Maintenance (7 hrs)

  • Validation and verification concepts.
  • Testing phases: development, release, and user testing.
  • Unit, component, system, requirements-based, scenario, performance, alpha, beta, acceptance tests.
  • Test-case development: boundary value, equivalence partitioning, basis path, control-structure testing.
  • Software change, evolution, maintenance process, and reengineering.

Chapter 6: Software Quality Assurance Process (4 hrs)

  • Software quality and reliability concepts.
  • Quality management and planning.
  • Standards and compliance (ISO, CMMI).
  • Capability assessment and process improvement.
  • Process/product standards, reviews, and inspections.

Chapter 7: Software Configuration Management (4 hrs)

  • Software configuration items.
  • Configuration activities: change management, version management, system building, system release.

Chapter 8: Advanced Software Engineering Concepts (4 hrs)

  • Software reuse and reuse strategies.
  • Application frameworks, software product lines, COTS reuse.
  • Cloud-based software engineering.
  • Artificial intelligence in software engineering.

Important Topics

  • Project-estimation metrics and risk exposure analysis.
  • Process-model selection criteria and agile scaling considerations.
  • Requirements quality and traceability practices.
  • Architecture style trade-offs for maintainability and performance.
  • Test strategy design across SDLC phases.
  • Automated and structured test-case generation methods.
  • Quality standards and compliance frameworks (ISO/CMMI).
  • Configuration/version management workflows.
  • Software reuse economics and cloud-native development practices.
  • AI-assisted software engineering opportunities and risks.

Practice Questions

  1. Choose a process model for a project scenario and justify with constraints.
  2. Create a requirements catalog and map it to analysis models.
  3. Design architecture for a system using one primary and one alternative style.
  4. Compute one estimation metric and identify top software risks with mitigation.
  5. Develop test cases using boundary-value and equivalence-partition techniques.
  6. Prepare a QA plan referencing standards and review/inspection checkpoints.
  7. Define configuration items and a release/version management strategy.
  8. Propose how cloud and AI tools can improve one software-engineering lifecycle phase.
