Pokhara University BE Computer Engineering semester 5 tutorial for Embedded System (course code ELX 320) with syllabus, key topics, concepts, and 5 practice questions.

Introduction

Embedded System in Semester 5 focuses on designing dedicated hardware-software systems for real-time applications. In Pokhara University BE Computer Engineering, this course combines microcontroller programming, operating-system-level control, communication interfaces, and digital hardware design practices. It helps students understand how computational logic is integrated into physical devices for specific tasks.

The syllabus begins with embedded-system fundamentals and AVR-based programming, then introduces RTOS concepts such as scheduling, synchronization, resource sharing, and priority inversion. This sequence develops both low-level programming confidence and system-level timing awareness. A dedicated unit on VHDL extends student capability toward hardware description and digital circuit realization.

The final units connect embedded design to practical deployment using serial/wireless communication protocols, peripheral interfacing, and IoT platforms. Together, these units prepare students to build application-oriented systems in domains like automation, robotics, health monitoring, and smart devices. Consistent lab-based implementation is the key to mastering this course.

What you will learn

  • Differentiate embedded systems from general-purpose computing systems.
  • Program AVR microcontrollers using Embedded C and interface I/O ports.
  • Use interrupts, timers, counters, and serial communication in AVR systems.
  • Understand RTOS concepts including scheduling and synchronization.
  • Design and model combinational/sequential circuits using VHDL.
  • Select and apply serial and wireless communication protocols.
  • Interface sensors, actuators, and display modules in embedded applications.
  • Relate embedded systems to IoT architecture and common platforms.

Syllabus Overview

Unit I: Introduction to Embedded Systems (3 hrs)

  • Definition and overview of embedded systems.
  • Embedded vs general-purpose systems.
  • Applications and domains: automotive, healthcare, industrial control, IoT.
  • Key components: microcontrollers, sensors, actuators, and peripherals.

Unit II: Programming for Embedded Systems (5 hrs)

  • Overview of AVR architecture.
  • Embedded C programming for microcontrollers.
  • Data types, control structures, pointers, and memory management.
  • AVR interrupt handling.
  • Input/output port interfacing on AVR.
  • Timers and counters in AVR.
  • Serial communication in AVR.

Unit III: Real-Time Operating Systems (RTOS) (5 hrs)

  • Concepts of real-time systems.
  • Introduction to RTOS platforms (e.g., FreeRTOS, VxWorks).
  • Task scheduling, context switching, and task synchronization.
  • Resource sharing, deadlock, and priority inversion.
  • Multithreading and multitasking in RTOS.

Unit IV: Embedded System Design using VHDL (5 hrs)

  • Introduction to VHDL.
  • Modeling styles in VHDL for combinational and sequential circuits.
  • Data types, subprograms, and packages.
  • VHDL realization of combinational and sequential circuits.

Unit V: Communication Protocols (3 hrs)

  • Serial communication: UART, SPI, I2C.
  • Wireless communication: Bluetooth, ZigBee, Wi-Fi, LoRa, GSM/GPRS.
  • TCP/IP basics in embedded networking.

Unit VI: Peripherals and Interfacing (4 hrs)

  • Sensor interfacing: analog and digital sensors.
  • Actuator interfacing and motor control (DC, stepper, servo).
  • PWM usage for brightness and speed control.
  • Display interfacing with LCD and seven-segment modules.

Unit VII: Internet of Things (IoT) and Embedded Systems (3 hrs)

  • IoT concepts and role of embedded systems in IoT.
  • IoT communication protocol: MQTT (basic concept).
  • Overview of IoT hardware platforms: Arduino, ESP32, Raspberry Pi.

Important Topics

  • Embedded-system architecture and domain-specific constraints.
  • AVR interrupt/timer programming patterns.
  • RTOS scheduling and synchronization trade-offs.
  • Priority inversion and deadlock handling in real-time systems.
  • VHDL modeling for combinational vs sequential logic.
  • UART/SPI/I2C protocol differences and use cases.
  • Sensor-actuator interfacing reliability and calibration basics.
  • PWM control for embedded actuation tasks.
  • MQTT communication flow in IoT systems.
  • Hardware-platform selection for prototype-to-product transition.

Practice Questions

  1. Compare embedded and general-purpose systems with real application examples.
  2. Write an Embedded C program using interrupt and timer on AVR.
  3. Design a simple RTOS task setup with synchronization and resource sharing.
  4. Model a sequential circuit in VHDL and explain testbench behavior.
  5. Implement UART or SPI communication between two embedded nodes.
  6. Interface one sensor and one actuator and validate input-output mapping.
  7. Design an IoT data-flow using MQTT and a chosen hardware platform.
  8. Propose an embedded project architecture including hardware, firmware, and communication choices.
