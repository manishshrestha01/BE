Introduction

Object Oriented Programming in C++ is a core transition course in Semester 2 where students move from procedural thinking to class-based software design. The course teaches how to model real problems as objects with attributes and behavior, then organize programs through abstraction, encapsulation, inheritance, and polymorphism. For Pokhara University BE Computer Engineering students, this subject provides the conceptual base for later software engineering, design patterns, and larger project development.

The syllabus starts with OOP foundations and C++ language basics, then progresses to classes, objects, constructors, and object-oriented design style. Inheritance and polymorphism units train students to create reusable and extensible code structures. These units are highly exam-relevant and also important for practical coding confidence.

The final units on templates, exception handling, and stream/file I/O complete the programming toolkit needed for robust C++ applications. Students who combine concept understanding with regular coding practice and output tracing usually perform strongly in both theory and practical evaluation.

What you will learn

  • Differentiate procedural and object-oriented programming paradigms.
  • Implement classes, objects, and member functions in C++.
  • Design reusable code using inheritance and access control modes.
  • Apply compile-time and run-time polymorphism techniques.
  • Use operator and function overloading correctly.
  • Build generic components with function and class templates.
  • Handle exceptions using try, throw, and catch mechanisms.
  • Perform file stream operations for persistent data handling.

Syllabus Overview

Unit 1: Object Oriented Concepts (8 hrs)

  • Object oriented programming paradigm and worldview.
  • A way of viewing world as interacting agents.
  • Procedure-oriented vs object-oriented programming.
  • Core features: class, object, abstraction, encapsulation, inheritance, polymorphism, message passing.
  • Computation as simulation and coping with complexity through abstraction mechanisms.
  • Object oriented analysis and design basics with responsibility-driven design idea.

Unit 2: Classes and Objects (8 hrs)

  • Origin and basic structure of C++.
  • Console input/output streams and manipulators.
  • Structure in C and C++ perspective.
  • Classes and objects, array of objects, and object modeling.
  • Class diagram and object diagram.
  • Access specifiers and visibility modes.
  • State, behavior, methods, and responsibilities of objects.
  • Implementation of abstraction, encapsulation, message passing, and data hiding in C++.

Unit 3: Inheritance (8 hrs)

  • Inheritance introduction and relationship modeling.
  • Public, private, and protected inheritance modes.
  • Single, multilevel, hierarchical, multiple, and hybrid inheritance.
  • Ambiguity resolution and virtual base class.
  • Constructor-destructor behavior in derived classes.
  • Subclass, subtype, and principle of substitutability.

Unit 4: Polymorphism (9 hrs)

  • Compile-time polymorphism: function/operator overloading.
  • Run-time polymorphism: virtual functions and overriding.
  • Overloading unary and binary operators.
  • this pointer and object pointer.
  • Pure virtual function and abstract class.
  • Virtual destructor and safe base-class cleanup.
  • Type conversion: basic-to-user-defined, user-defined-to-basic, and user-defined-to-user-defined.

Unit 5: Templates (5 hrs)

  • Generic programming mindset.
  • Function template and class template.
  • STL overview: containers, algorithms, iterators.

Unit 6: Exception Handling and Stream I/O (7 hrs)

  • Error vs exception and exception handling flow.
  • try-throw-catch mechanism and multiple exception handling.
  • File stream class hierarchy, opening/closing files, and reading/writing objects.

Important Topics

  • OOP feature mapping with practical C++ examples.
  • Object oriented analysis and responsibility-based design basics.
  • Class design with data hiding and visibility control.
  • Inheritance mode impact on accessibility.
  • Virtual base class use in multipath inheritance.
  • Operator overloading rules and limitations.
  • Runtime dispatch with virtual function and virtual destructor behavior.
  • Abstract class and interface-like design usage.
  • Template syntax, STL usage, and code reuse strategy.
  • Exception-safe coding patterns in C++.
  • File stream lifecycle, object serialization, and common I/O pitfalls.

Practice Questions

  1. Compare POP and OOP with one code-level scenario showing abstraction, encapsulation, and message passing.
  2. Design a class and object diagram, then implement the class in C++ with proper visibility modes.
  3. Implement multilevel or multiple inheritance and show ambiguity resolution using virtual base class.
  4. Write a program demonstrating function overloading and virtual function overriding.
  5. Implement unary or binary operator overloading and justify operator overloading constraints.
  6. Create a generic function or class template for reusable operations.
  7. Handle multiple exception cases in an arithmetic or input-validation program using try-throw-catch.
  8. Write/read object data from file streams with proper exception and resource handling.
