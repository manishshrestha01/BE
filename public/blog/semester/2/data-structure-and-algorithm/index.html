Introduction

Data Structure and Algorithm is one of the most important computing subjects in Semester 2 because it develops the foundation for efficient problem solving. The course teaches how data should be organized and which algorithms should be selected for reliable time and space performance. In Pokhara University BE Computer Engineering, this subject directly supports future courses in operating systems, database systems, machine learning, compiler design, and software engineering.

The syllabus begins with data structure fundamentals and algorithm analysis, then introduces stack, recursion, queue, and linked list based problem solving. It progresses to trees and graph structures that are essential for hierarchical and network-like computation models. The sorting and searching units reinforce complexity reasoning and practical implementation choices.

Students who practice this subject with dry-run traces, complexity estimation, and implementation comparison generally improve quickly. Rather than memorizing definitions, focus on operation costs, use cases, and trade-offs between representations. This guide is organized to support that exam-and-interview friendly preparation style.

What you will learn

  • Explain the need, characteristics, and categories of data structures.
  • Analyze algorithm complexity using best/worst/average case approaches.
  • Implement stack operations and recursion-based solutions.
  • Use queue and linked list variants for dynamic data handling.
  • Represent and traverse trees including binary and search trees.
  • Compare sorting methods based on stability and complexity.
  • Apply searching and hashing techniques for efficient retrieval.
  • Model and solve graph problems using traversal and MST algorithms.

Syllabus Overview

Unit 1: Introduction (5 hrs)

  • Philosophy of data structures with need, characteristics, and types.
  • Abstract data type (ADT) and data structure relationship.
  • Algorithm design strategies: divide and conquer, greedy, backtracking.
  • Algorithm analysis with best, worst, and average case ideas.
  • Asymptotic notations: Big O, Big Omega, Big Theta.

Unit 2: Stack and Recursion (7 hrs)

  • Stack definition, ADT, and array implementation.
  • Expression evaluation in infix/postfix forms.
  • Expression conversion: infix to postfix and postfix to infix.
  • Recursion principles and recursive algorithm patterns.
  • Recursion vs iteration and recursion with stack relation.

Unit 3: Queue and Linked List (10 hrs)

  • Queue ADT, basic operations, and array implementation.
  • Circular queue, deque, and priority queue concepts.
  • List ADT and linked list operations.
  • Singly, doubly, and circular linked list with applications.
  • Linked implementation of stack and queue.

Unit 4: Tree (7 hrs)

  • Tree definitions, terminologies, and applications.
  • General tree and game tree concepts.
  • Binary tree representation (array and linked forms).
  • Tree traversals: preorder, inorder, postorder.
  • Application context such as Huffman coding.
  • Binary search tree operations and construction.
  • Balanced binary tree, AVL tree, and B-tree (need and application).

Unit 5: Sorting Algorithms (5 hrs)

  • Internal/external and stable/unstable sorting concept.
  • Insertion, selection, bubble, and exchange sort.
  • Quick sort and merge sort.
  • Radix, shell, and heap sort overview.

Unit 6: Searching Algorithms and Hashing (5 hrs)

  • Sequential search and binary search comparison.
  • Hash functions and hash table structure.
  • Hashing as data structure and search mechanism.
  • Collision in hash table and collision resolution techniques.
  • Load factor and rehashing basics.

Unit 7: Graphs (6 hrs)

  • Graph terminology, types, and representations.
  • Adjacency matrix, incidence matrix, adjacency list.
  • Transitive closure and Warshall algorithm.
  • BFS, DFS, and topological sort.
  • Minimum spanning tree via Kruskal and Prim algorithms.
  • Shortest-path problem types and basic solution strategies.

Important Topics

  • Asymptotic notation interpretation in algorithm comparison.
  • Expression conversion/evaluation using stack.
  • Recursive design and recursion tree reasoning.
  • Queue variants and linked-list based implementations.
  • BST insertion/deletion/search logic and AVL balancing idea.
  • Traversal order and tree representation trade-offs.
  • Complexity comparison of major sorting algorithms.
  • Hash function choice, load factor, and collision handling.
  • Graph traversal correctness and use cases.
  • MST and shortest-path algorithm step tracking.

Practice Questions

  1. Analyze the complexity of two algorithms and classify with Big O, Big Omega, and Big Theta.
  2. Convert an infix expression to postfix and evaluate it using stack operations.
  3. Implement circular queue operations and explain overflow/underflow cases.
  4. Create and traverse a binary tree in preorder, inorder, and postorder.
  5. Construct a BST from given keys and perform search/deletion, then discuss AVL rebalancing.
  6. Compare quick sort and merge sort with respect to complexity and stability.
  7. Design a hash table for integer keys and discuss collision resolution with load factor effect.
  8. Apply BFS/DFS on a sample graph, then compute MST and one shortest-path result.
