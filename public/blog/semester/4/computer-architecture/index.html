Pokhara University BE Computer Engineering semester 4 tutorial for Computer Architecture (course code CMP 262) with syllabus, key topics, concepts, and 5 practice questions.

Introduction

Computer Architecture in Semester 4 explains how modern computing systems are designed from instruction-level behavior to multicore performance structure. The course in Pokhara University BE Computer Engineering bridges digital design concepts with processor-level organization, helping students understand why architectural choices affect speed, power, and scalability. It covers both conceptual architecture and practical modeling through tutorial and laboratory tasks including VHDL-oriented exercises.

The early units establish architecture basics, register-transfer-level operations, and processor organization. Students then study control unit design through hardwired and microprogrammed approaches, followed by arithmetic algorithms used internally by CPUs. These units are crucial because they connect instruction execution theory with hardware-level data movement and control sequencing.

The later part of the syllabus focuses on pipelining, memory hierarchy, cache policies, I/O processing, parallel architectures, and multicore systems. This sequence develops an understanding of real performance bottlenecks and optimization strategies used in modern processors. Regular practice with algorithm tracing, timing interpretation, and architecture comparison makes this subject highly useful for systems and hardware-oriented engineering roles.

What you will learn

  • Explain architecture and organization concepts of computer systems.
  • Use RTL and micro-operations to describe processor-level data transfer.
  • Interpret CPU organization, datapaths, and instruction-cycle execution.
  • Compare hardwired and microprogrammed control-unit architectures.
  • Apply binary arithmetic algorithms used in processor design.
  • Analyze pipelining stages, hazards, and mitigation approaches.
  • Explain memory hierarchy, cache mapping, replacement, and write policies.
  • Understand I/O organization, parallel processing models, and multicore performance issues.

Syllabus Overview

Unit 1: Introduction to Architecture [4 hrs]

  • Overview of computer organization and architecture.
  • Hierarchy structure of computer systems.
  • Computer evolution and generations.
  • Computer components and functions.
  • Future trends in computing.
  • Review of instruction sets, addressing modes, and instruction formats.

Unit 2: Register Transfer Language and Micro Operations [4 hrs]

  • Register transfer and RTL notation.
  • Micro-operations and data-transfer micro-operations.
  • Arithmetic, logical, and shift micro-operations.
  • Introduction to HDL and VHDL.
  • VHDL programming for adder, mux, and ALU.

Unit 3: Processor Organization [5 hrs]

  • CPU organization and structure.
  • Register organization and datapaths.
  • Instruction cycle and T-states.
  • Arithmetic and logical unit organization.
  • Design principles for modern systems.

Unit 4: Control Unit [5 hrs]

  • Processor control fundamentals.
  • Hardwired control unit and control logic.
  • Microinstruction formats.
  • Microprogrammed control unit architecture.
  • Microinstruction sequencing and execution.
  • Applications of hardwired and microprogrammed control units.
  • RISC and CISC architecture comparison.

Unit 5: Computer Arithmetic [7 hrs]

  • Integer representation and integer arithmetic.
  • Unsigned binary addition and subtraction.
  • Unsigned binary multiplication algorithm and Booth multiplication.
  • Unsigned binary division algorithm.
  • Floating-point representation concepts.

Unit 6: Pipelining [4 hrs]

  • Pipelining fundamentals and arithmetic pipeline.
  • Instruction pipelining structure.
  • Pipeline conflicts and resolution methods.
  • RISC pipeline.
  • Register windowing and register renaming.

Unit 7: Memory Organization [4 hrs]

  • Memory hierarchy with main and auxiliary memory.
  • Associative memory and cache memory.
  • Cache mapping: direct, associative, set-associative.
  • Cache write policies and replacement algorithms (FIFO, LRU, LFU).

Unit 8: Input-Output Processing [4 hrs]

  • Peripheral devices and I/O modules.
  • I/O interfaces and transfer techniques.
  • Modes of transfer: programmed, interrupt-driven, and DMA.
  • I/O processor and I/O channels.
  • GPU, TPU, and external interfaces (FireWire, InfiniBand).

Unit 9: Parallel Processing [4 hrs]

  • Parallel processing concepts and uniprocessor parallelism.
  • Multiprocessor systems and key characteristics.
  • Flynn classification.
  • Interconnection structures in multiprocessors.
  • Vector and array processing.
  • Introduction to multithreaded architecture.

Unit 10: Multi-core Computer (4 hrs)

  • Hardware performance issues.
  • Software performance issues.
  • Multicore organization.
  • Dual-core, quad-core, and octa-core concepts.
  • Power-efficient processor design trends.

Important Topics

  • Instruction-format and addressing-mode impact on execution.
  • RTL and micro-operation sequencing in datapaths.
  • Hardwired vs microprogrammed control trade-offs.
  • Booth multiplication and binary division algorithms.
  • Pipeline hazards and mitigation strategies.
  • Cache mapping, write policy, and replacement behavior.
  • Interrupt-driven I/O vs DMA transfer models.
  • Flynn taxonomy for parallel architectures.
  • Multithreaded and multicore performance bottlenecks.
  • Power-performance balance in modern processors.

Practice Questions

  1. Explain the hierarchy of computer architecture with a functional block-level diagram.
  2. Write RTL statements and micro-operations for a given register-transfer task.
  3. Compare hardwired and microprogrammed control units with one design scenario.
  4. Perform multiplication using Booth algorithm and explain each step.
  5. Analyze a simple pipeline and identify structural/data/control hazards.
  6. Evaluate cache hit/miss behavior under direct and set-associative mapping.
  7. Differentiate programmed I/O, interrupt I/O, and DMA with use-case examples.
  8. Classify architectures using Flynn model and discuss multicore scaling challenges.
