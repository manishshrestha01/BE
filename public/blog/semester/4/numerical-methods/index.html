Introduction

Numerical Methods in Semester 4 teaches how to solve mathematical problems that do not have convenient closed-form solutions. The course in Pokhara University BE Computer Engineering focuses on algorithmic computation, approximation, and error-aware modeling. Instead of only symbolic manipulation, students learn iterative and discretized techniques that can be implemented in tools such as MATLAB, C, or C++ for engineering applications.

The syllabus starts with nonlinear equation solving and interpolation frameworks, then covers numerical differentiation and integration. These topics build the base for practical data fitting and approximate analysis when input is discrete or noisy. The middle units on linear algebraic systems and eigenvalue computation are especially useful for engineering simulations where matrix problems are central.

The final units cover numerical ODE and PDE solution methods including Runge-Kutta, shooting method, and finite-difference approaches for Laplace, Poisson, and heat equations. This makes the course highly practical for computational modeling work in later semesters. Students who regularly compare accuracy, convergence, and computational cost across methods usually perform strongly in both theory and lab components.

What you will learn

  • Solve nonlinear equations using bracketing and open methods.
  • Estimate interpolation and approximation functions from discrete data.
  • Apply numerical differentiation and integration rules with error awareness.
  • Solve linear systems using elimination, factorization, and iterative schemes.
  • Compute eigenvalue and eigenvector using power-method approach.
  • Use Runge-Kutta methods for first and second-order ODEs.
  • Solve boundary-value ODE problems using shooting method.
  • Apply finite-difference methods for Laplace, Poisson, and heat equations.

Syllabus Overview

Unit 1: Solution of Non-linear Equations (5 hrs)

  • Introduction and importance of numerical methods.
  • Approximation and computation error basics.
  • Bisection method.
  • Secant method.
  • Newton-Raphson method.
  • Fixed-point iterative method.

Unit 2: Interpolation and Approximation (5 hrs)

  • Lagrange interpolation.
  • Finite differences: forward, backward, and divided differences.
  • Newton interpolation: forward and backward.
  • Least-square fitting for linear and nonlinear curves.
  • Cubic spline interpolation.

Unit 3: Numerical Differentiation and Integration (4 hrs)

  • Numerical differentiation formulae.
  • Trapezoidal rule and Simpson 1/3 and 3/8 rules.
  • Romberg integration.
  • Gaussian integration using 2-point and 3-point formulae.

Unit 4: Solution of System of Linear Algebraic Equations (6 hrs)

  • Gauss elimination and pivoting concepts.
  • Ill-conditioned linear systems.
  • LU factorization methods: Doolittle, Crout, Cholesky.
  • Iterative methods: Jacobi and Gauss-Seidel.
  • Eigenvalue and eigenvector by power method.

Unit 5: Solution of Ordinary Differential Equations (6 hrs)

  • Review of ordinary differential equations.
  • Runge-Kutta methods (first, second, fourth) for first and second-order equations.
  • Boundary-value solution using shooting method.

Unit 6: Numerical Solution of Partial Differential Equation (4 hrs)

  • Classification of PDE: elliptic, parabolic, hyperbolic.
  • Laplace equation solution with standard 5-point formula and iterative methods.
  • Poisson equation solution by finite-difference approximation.
  • One-dimensional heat equation solution by Schmidt method.

Important Topics

  • Convergence and error behavior of nonlinear root-finding methods.
  • Interpolation formula selection for tabulated data.
  • Finite-difference operator usage in derivative approximation.
  • Comparison of numerical integration formulas by accuracy order.
  • Pivoting and conditioning effects in linear systems.
  • LU decomposition vs iterative solvers trade-offs.
  • Power-method convergence for dominant eigenvalue.
  • Runge-Kutta method formulation and step-size influence.
  • Finite-difference stencil setup for Laplace and Poisson equations.
  • Schmidt scheme interpretation for heat equation progression.

Practice Questions

  1. Solve a nonlinear equation using bisection, secant, and Newton-Raphson, then compare iterations.
  2. Construct interpolation polynomial and estimate function value at given point.
  3. Evaluate a definite integral using trapezoidal, Simpson, and Gaussian methods.
  4. Solve a linear system using Gauss elimination and Gauss-Seidel for comparison.
  5. Apply LU factorization to solve a matrix equation and discuss computational benefit.
  6. Find dominant eigenvalue and eigenvector using power method.
  7. Solve an ODE IVP using RK4 and compare with lower-order RK method.
  8. Discretize and solve a simple Laplace or Poisson grid problem using finite differences.
