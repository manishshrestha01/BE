Introduction

Advanced Programming with Java in Semester 4 expands Java learning from language fundamentals to application-level development. In Pokhara University BE Computer Engineering, this course combines core OOP practice, graphical user interface design, networking, database integration, web components, and advanced frameworks. It is structured to move students from writing standalone programs to building connected and layered software systems.

The early units strengthen Java language foundations and object-oriented design patterns using inheritance, abstraction, polymorphism, and interface-based programming. GUI units then introduce AWT, Swing, and JavaFX for desktop application development with layout managers, event handling, and reusable components. This gives students practical understanding of user interaction design in Java ecosystems.

The later units focus on network programming, JDBC, servlets/JSP, ORM concepts, Hibernate, Spring Boot basics, and concurrency. These topics align closely with real software engineering workflows and enterprise-style application development. Students who practice each unit with small implementation projects and proper exception-handling discipline gain strong practical confidence in Java development.

What you will learn

  • Build structured Java applications using classes, packages, and collections.
  • Apply advanced OOP principles in Java with inheritance and abstraction.
  • Develop GUI components using Swing and JavaFX with event handling.
  • Implement socket-based network communication with TCP and UDP.
  • Use RMI and introductory CORBA concepts in distributed Java context.
  • Connect Java applications to databases via JDBC with secure queries.
  • Build servlet/JSP-based web components with session and request handling.
  • Understand advanced Java topics: ORM, Hibernate, Spring Boot basics, concurrency, and design patterns.

Syllabus Overview

Unit 1: Basics of Programming in Java (7 hrs)

  • Java architecture, class paths, and sample program structure.
  • Classes, objects, and constructors.
  • Packages and data types.
  • Conditional statements and access modifiers.
  • Exception handling essentials.
  • Java collections overview.

Unit 2: Object Oriented Principles in Java (6 hrs)

  • Review of object-oriented principles.
  • Superclass, subclass, inheritance, and member access.
  • Types of inheritance and use of extends/super keywords.
  • Method overriding and overloading.
  • Final classes/methods and abstract classes/methods.
  • Upcasting vs downcasting.
  • Interfaces and implementations.

Unit 3: Building Components using Swing and JavaFX (6 hrs)

  • Introduction to AWT and Swing concepts, applets, hierarchy, components/containers.
  • Layout management and GUI controls.
  • Menu elements, tooltips, dialogs, and frames.
  • Event handling and listener interfaces with action events.
  • JavaFX vs Swing, JavaFX layouts, and JavaFX UI controls.

Unit 4: Distributed Network Programming (8 hrs)

  • TCP, UDP, IP address, and port fundamentals.
  • Socket programming using TCP and UDP.
  • URL and URLConnection usage.
  • Email handling with Java Mail API.
  • RMI architecture and implementation basics.
  • CORBA architecture, IDL, and simple CORBA program concept.
  • RMI vs CORBA comparison.

Unit 5: Database Connectivity with Java (5 hrs)

  • JDBC architecture and driver types.
  • Connection and statement management.
  • Result set handling and exceptions.
  • DDL and DML operation flow.
  • SQL injection prevention with prepared statements.
  • Row sets, transactions, and SQL escapes.

Unit 6: Servlets and JSP (6 hrs)

  • Web application overview and HTTP methods/responses.
  • Servlet lifecycle and servlet API usage.
  • Form reading and request processing (GET/POST).
  • Database connectivity through servlets.
  • Cookie and session management.

Unit 7: Advanced Topics in Java (7 hrs)

  • ORM overview and Hibernate basics.
  • Web framework introduction and Spring Boot basics.
  • Concurrency and multithreading in Java.
  • Design patterns: Singleton, Factory, and Abstract Factory.

Important Topics

  • Class design, exception flow, and collection usage patterns.
  • Inheritance and interface-driven extensible design.
  • Swing/JavaFX event-driven architecture.
  • TCP vs UDP socket design decisions.
  • RMI and CORBA conceptual architecture differences.
  • JDBC transaction handling and prepared statement security.
  • Servlet lifecycle and state management with sessions.
  • Hibernate mapping fundamentals.
  • Concurrency primitives and thread-safe coding mindset.
  • Factory-style design patterns for maintainable code.

Practice Questions

  1. Design a Java class hierarchy using inheritance, abstraction, and interfaces.
  2. Build a Swing or JavaFX form with event handling and input validation.
  3. Create a TCP or UDP socket program for client-server messaging.
  4. Implement a JDBC module with prepared statements for CRUD operations.
  5. Write a servlet that handles GET/POST requests and maintains session data.
  6. Compare RMI and CORBA architecture with one use-case each.
  7. Build a small module using Hibernate and explain ORM mapping choices.
  8. Demonstrate a multithreaded Java task and apply one design pattern.
