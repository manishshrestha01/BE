Introduction

Data Science and Analytics in Semester 7 provides a practical framework for extracting meaningful patterns from real datasets. In Pokhara University BE Computer Engineering, the course integrates preprocessing, descriptive statistics, regression, classification, clustering, and time-series analysis with causal reasoning basics. The emphasis is on applying appropriate methods responsibly rather than blindly running algorithms.

The early units build foundational literacy in data types, preprocessing, empirical distributions, and correlation analysis. This base is essential because model quality depends heavily on data quality, variable understanding, and correct interpretation. Students also learn significance concepts such as p-value, t-value, and chi-squared to support evidence-based conclusions.

Later units develop numeric and mixed-type analysis through multivariate regression, kernel methods, PCA, CART, logistic regression, clustering, and ARMA/ARIMA models. The course closes with introductory causal-analysis ideas such as Granger causality and DAG perspective. With consistent practical work in tools like Python, R, or Weka, this subject becomes highly useful for both research and industry analytics tasks.

What you will learn

  • Describe the full data-analysis pipeline and knowledge-discovery process.
  • Apply preprocessing methods including cleaning, integration, transformation, and discretization.
  • Interpret empirical distributions for numeric and categorical variables.
  • Perform correlation analysis across variable types with appropriate techniques.
  • Build and evaluate numeric-data models using multivariate and non-parametric regression.
  • Use PCA for latent-structure discovery and dimensionality insight.
  • Apply classification, logistic regression, and clustering to categorical or mixed-type data.
  • Use ARMA/ARIMA and basic causal-analysis concepts for time-dependent data problems.

Syllabus Overview

Unit I: Data Analysis Pipeline (3 hrs)

  • Knowledge discovery from database process.
  • Structured vs unstructured data and examples.
  • Data preprocessing overview.
  • Data cleaning, integration, transformation, and discretization.

Unit II: Statistical Foundation (8 hrs)

  • Variable types: numeric and categorical.
  • Empirical distributions for numeric and categorical data.
  • Histograms, normal/exponential/power-law views and bar/binomial/Zipf contexts.
  • Correlation analysis: Pearson and cross-tabulation approaches.
  • Correlation assessment across mixed variable types.
  • Statistical significance basics: p-value, t-value, and chi-squared.

Unit III: Numeric Data (9 hrs)

  • Multivariate linear regression.
  • Matrix formulation and OLS estimation.
  • Measures of fit: R-squared and adjusted R-squared.
  • Multicollinearity and variance-inflation factor concept.
  • Non-parametric regression using Nadaraya-Watson kernel method.
  • Bandwidth-selection rules in kernel regression.
  • Principal component analysis (PCA) formulation and interpretation.

Unit IV: Categorical and Mixed-type Data (5 hrs)

  • Classification with decision trees and CART algorithm.
  • Logistic regression for categorical outcomes.
  • Variable-importance techniques: permutation tests and partial-dependence plots.
  • Clustering with k-means and distance metrics for mixed-type data.

Unit V: Time and Causality (5 hrs)

  • Time-series analysis fundamentals.
  • Autocorrelation and stationarity.
  • ARMA and ARIMA models.
  • Lag selection using AIC and BIC.
  • Causation vs correlation.
  • Granger causality and causal DAG overview.

Important Topics

  • Data-preprocessing quality and reproducibility.
  • Distribution interpretation for different variable types.
  • Pearson vs cross-tabulation correlation use-cases.
  • Significance testing with p, t, and chi-squared values.
  • OLS assumptions and multicollinearity impact.
  • Kernel-regression bandwidth sensitivity.
  • PCA component interpretation and dimensionality reduction.
  • CART and logistic-regression decision boundaries.
  • ARMA/ARIMA model selection and lag diagnostics.
  • Correlation vs causation boundaries in analysis.

Practice Questions

  1. Design a preprocessing workflow for a dataset containing both structured and unstructured fields.
  2. Plot empirical distributions for numeric and categorical variables and interpret key differences.
  3. Perform correlation analysis for numeric-numeric and categorical-categorical variable pairs.
  4. Fit a multivariate linear-regression model and explain R-squared and VIF outcomes.
  5. Apply kernel regression and discuss the effect of bandwidth choice.
  6. Compute principal components on a small dataset and interpret dominant factors.
  7. Build a CART or logistic-regression model and assess variable importance.
  8. Model a time series using ARMA/ARIMA and discuss one causality check using Granger framework.
