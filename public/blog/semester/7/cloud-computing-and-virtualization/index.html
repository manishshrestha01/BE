Introduction

Cloud Computing and Virtualization in Semester 7 introduces scalable on-demand computing as a core engineering platform. In Pokhara University BE Computer Engineering, this course covers cloud service/deployment models, virtualization technologies, storage architectures, resource management, and cloud security controls. The focus is not only conceptual; students are expected to reason about deployable architecture decisions.

The course first establishes cloud foundations through NIST concepts, architecture principles, SaaS/PaaS/IaaS, deployment models, and ethical concerns. It then develops virtualization and VPC understanding including hypervisors, containerization, VM management, and cloud-network components. These topics are essential for building modern infrastructure with flexibility and cost awareness.

The later units cover cloud storage choices, scaling and load-balancing mechanisms, SLA-driven resource management, and cloud security with IAM and disaster management concerns. Combined with practical work on VM provisioning, SQL/NoSQL services, autoscaling, and VPC setup, this subject gives direct operational skills for cloud-native engineering roles.

What you will learn

  • Explain cloud-computing foundations, reference architecture, and evolution.
  • Differentiate service models (SaaS, PaaS, IaaS) and deployment models.
  • Use virtualization concepts including hypervisors, VMs, and containerization basics.
  • Design VPC-oriented network structures with VPN, DNS, and multihoming considerations.
  • Compare cloud storage and database models including SQL, NoSQL, and graph systems.
  • Apply scaling, load balancing, monitoring, SLA, and billing management concepts.
  • Understand cloud-security threats and security mechanisms such as SSO, IAM, and digital signatures.
  • Plan practical cloud solutions with autoscaling, access control, and resilience concerns.

Syllabus Overview

Unit 1: Introduction (8 hrs)

  • Need for cloud computing and NIST definition.
  • Cloud characteristics, benefits, and applications.
  • Cloud reference model and NIST architecture.
  • Design principles and infrastructural constraints.
  • Evolution of cloud computing.
  • Cloud service model: SaaS, PaaS, and IaaS.
  • Cloud deployment model: public, private, hybrid, and community.
  • Jericho Cloud Cube model and cloud challenges/ethical issues.

Unit 2: Virtualization (7 hrs)

  • Virtualization technologies and hypervisors (Type 1 and Type 2).
  • Overview of containerization and Kubernetes.
  • Virtual-machine management and configuration.
  • Virtualization levels: hardware, software, operating system, data, and networking.
  • Virtual private cloud and virtual private network concepts.
  • DNS services and cloud networking.
  • Multihoming fundamentals.

Unit 3: Storage in Cloud Computing (5 hrs)

  • Database as a service (DBaaS).
  • Storage models and file-system concepts.
  • Parallel and distributed file systems.
  • Cloud storage services: object, file, block, and archive storage.
  • Elastic storage and data redundancy.
  • Relational (SQL), non-relational (NoSQL), and graph databases.

Unit 4: Resource Management in Cloud Computing (5 hrs)

  • Scaling strategies and scaling types.
  • Load balancing and high availability.
  • Cloud monitoring mechanisms and usage/audit/pay-per-use monitors.
  • Service-level agreement (SLA) and types.
  • Billing-management system in cloud platforms.

Unit 7: Security in Cloud Computing (5 hrs)

  • Cloud security threats and attack surface.
  • Security as a service.
  • Dimensions of cloud security.
  • Security mechanisms including SSO, IAM, hashing, and digital signatures.
  • Disaster management in cloud computing.
  • Challenges of cloud security.

Important Topics

  • NIST-based cloud architecture understanding.
  • SaaS/PaaS/IaaS and deployment-model trade-offs.
  • Hypervisor and VM management decisions.
  • VPC/VPN design and cloud-network planning.
  • Object/block/file storage selection criteria.
  • Autoscaling and load-balancing strategy.
  • SLA and monitoring-driven operations.
  • IAM and identity-control fundamentals.
  • Cloud threat modeling and disaster readiness.
  • Billing and resource-optimization logic.

Practice Questions

  1. Map a real application to appropriate cloud service and deployment models with justification.
  2. Differentiate hypervisor-based virtualization and containerization for a deployment scenario.
  3. Design a basic VPC architecture with subnet, gateway, and DNS requirements.
  4. Choose storage and database services for an application with mixed relational and unstructured data.
  5. Propose an autoscaling and load-balancing policy for variable traffic demand.
  6. Define SLA parameters and cloud-monitoring signals for one production workload.
  7. Prepare a cloud-security control plan using IAM, SSO, and data-protection mechanisms.
  8. Outline disaster-recovery steps for a cloud-hosted service with availability objectives.
