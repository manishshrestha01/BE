Introduction

Network and Cyber Security in Semester 7 builds the security foundation required to design and operate trustworthy digital systems. In Pokhara University BE Computer Engineering, this course links mathematical cryptography with real security architecture, protocol-level controls, and web application protection. It is a core professional-readiness subject because modern software and infrastructure work always involves security decisions.

The course begins with network-security concepts, threat models, and classical cryptography, then develops into modern symmetric and asymmetric mechanisms such as DES/AES, RSA, Diffie-Hellman, ElGamal, and elliptic-curve approaches. Students also study hashing, MAC/HMAC, digital signatures, and key-establishment problems to understand authenticity and integrity in practical systems.

The final units focus on cyber and web security implementation through SSL/TLS, IPsec, email security, and OWASP-centered secure coding/testing practices. By connecting algorithmic foundations with standards and security testing workflows, this course helps students become capable of both analyzing vulnerabilities and proposing robust mitigations.

What you will learn

  • Explain security terminology, attack types, and network security models.
  • Apply symmetric-key cryptography concepts and block/stream cipher structures.
  • Understand asymmetric cryptography and public-key exchange mechanisms.
  • Use hashing and digital-signature methods for authentication and integrity.
  • Analyze key-establishment approaches and related attack surfaces.
  • Describe SSL/TLS, IPsec, and email-security frameworks in cyber defense.
  • Apply OWASP-aligned secure-development and security-testing practices.
  • Interpret common web vulnerabilities and propose practical mitigations.

Syllabus Overview

Unit I: Introduction to Network Security (3 hrs)

  • Security fundamentals and attack taxonomy.
  • Virus, worm, and trojan horse overview.
  • Intruder, hacker, firewall role, and DMZ concept.
  • CIA triad, security services, and security mechanisms.
  • Network security model and network access security model.

Unit II: Symmetric Key Cryptography (9 hrs)

  • Cryptology, cryptography, and cryptanalysis.
  • Conventional cryptography and single-key encryption.
  • Computationally secure algorithm concept.
  • Stream, substitution, and transposition ciphers.
  • Block ciphers and Feistel structure.
  • DES, 2DES, 3DES, and AES overview.

Unit III: Asymmetric Key Cryptography (9 hrs)

  • Need for public-key cryptography and asymmetric model.
  • Prime-factorization problem and RSA encryption.
  • Discrete logarithm problem.
  • Diffie-Hellman key exchange.
  • ElGamal encryption.
  • Elliptic-curve cryptography.

Unit IV: Authentication System and Key Establishment (9 hrs)

  • Hash and secure-hash algorithm concepts.
  • Authentication in symmetric cryptography: MAC, message digest, and HMAC variants.
  • Authentication in asymmetric cryptography: digital signature, RSA signature, and DSS.
  • Key-establishment issues including n-squared distribution problem and KDC.
  • Man-in-the-middle attack and digital certificate concepts.

Unit V: Cyber (Web) Security (9 hrs)

  • Approaches to web security.
  • Secure Socket Layer architecture and Transport Layer Security.
  • IPsec with transport and tunnel modes.
  • Email security mechanisms.
  • Pretty Good Privacy and S/MIME.

Unit VI: Web Application Security Standards and Practices (6 hrs)

  • OWASP Top 10 overview.
  • Authentication and authorization controls.
  • Data protection in storage and transit with strong validation.
  • Error/exception handling, user/session management, auditing and logging.
  • Security testing for access-control, cryptographic, integrity, and monitoring failures.
  • Injection classes: XSS, command, LDAP, XML, and template injection.
  • Insecure design, vulnerable/outdated components, and SSRF mitigation strategies.

Important Topics

  • CIA triad and layered security mechanisms.
  • DES/AES and Feistel structure understanding.
  • RSA, DH, ElGamal, and ECC comparison.
  • MAC/HMAC and digital-signature integrity workflows.
  • Key-distribution challenges and digital certificates.
  • TLS and IPsec deployment basics.
  • Email-security standards (PGP and S/MIME).
  • OWASP Top 10 risk categories.
  • Injection and access-control vulnerability mitigation.
  • Security testing and logging-monitoring controls.

Practice Questions

  1. Differentiate malware, intrusion, and attack vectors with one network-security scenario.
  2. Explain Feistel structure and compare AES with DES/3DES in practical security terms.
  3. Demonstrate RSA or Diffie-Hellman workflow using a small numerical example.
  4. Compare MAC, HMAC, and digital signatures for integrity and authenticity requirements.
  5. Describe a key-establishment protocol and analyze one possible man-in-the-middle risk.
  6. Differentiate TLS and IPsec use-cases in enterprise deployments.
  7. Map a sample web application to relevant OWASP Top 10 vulnerabilities.
  8. Prepare a short security-testing checklist covering injection, access-control, and logging failures.
