Introduction

Machine Learning in Semester 6 is a core intelligence-focused subject where students learn how to build systems that improve from data instead of relying only on hard-coded rules. In Pokhara University BE Computer Engineering, this course balances foundations and implementation by covering end-to-end workflow: problem definition, data preparation, model selection, validation, tuning, and deployment. This workflow perspective is critical because many practical failures in ML projects come from process gaps rather than algorithm choice.

The course develops classical supervised and unsupervised learning first, then moves toward deeper neural-network architectures. Regression, classification, clustering, dimensionality reduction, and ensemble methods are taught as practical tools with clear assumptions and limitations. This helps students choose models based on data behavior and project constraints instead of memorizing algorithm names. Topics like bias-variance, regularization, and kernel methods also build strong reasoning for model generalization.

The advanced part introduces feedforward networks, CNNs, RNNs, LSTM/GRU, and modern model-evaluation metrics. Students learn to measure performance with accuracy, precision-recall, ROC/PR curves, MAE/MSE/RMSE, and R-squared while using validation strategies like train-test split and k-fold cross-validation. With consistent coding practice and error analysis, this subject becomes a direct bridge to applied AI, data science, and research-oriented project work.

What you will learn

  • Describe the complete machine-learning lifecycle from data collection to deployment.
  • Build supervised models for regression and classification tasks.
  • Apply regularization and bias-variance analysis to improve generalization.
  • Implement unsupervised techniques such as clustering and dimensionality reduction.
  • Design neural-network models including MLP, CNN, and sequence-oriented RNN variants.
  • Use optimization and loss-function concepts for network training.
  • Evaluate models using classification and regression metrics.
  • Validate and tune models with cross-validation, grid search, and random search.

Syllabus Overview

Unit I: Introduction to Machine Learning (5 hrs)

  • Definition and evolution of machine learning.
  • Learning paradigms: supervised, unsupervised, reinforcement, and active learning.
  • ML workflow: problem definition, data preprocessing, model selection, evaluation, and deployment.
  • Common challenges: data quality, computational complexity, interpretability, and ethics.

Unit II: Supervised Learning (10 hrs)

  • Regression and classification fundamentals.
  • Linear regression: simple, multiple, and polynomial models.
  • Regularization techniques: ridge and lasso.
  • Bias-variance trade-off.
  • Support vector regression.
  • Classification with logistic regression (binary and multiclass).
  • K-nearest neighbors and support vector machines.
  • Hyperplanes, support vectors, and kernels (linear, polynomial, RBF).
  • Decision-tree construction/pruning and ensemble methods (bagging, random forest).

Unit III: Unsupervised Learning (10 hrs)

  • Unsupervised-learning concepts and categories.
  • Clustering methods: k-means, hierarchical, agglomerative, divisive, and density-based approaches.
  • DBSCAN basics and use-cases.
  • Dimensionality reduction using PCA and LDA.
  • Association-rule learning overview.

Unit IV: Artificial Neural Network (12 hrs)

  • Neural-network introduction and architectures: feedforward, convolutional, and recurrent.
  • Perceptron, single-layer perceptron, and multilayer perceptron.
  • Training concepts: forward propagation, backpropagation, and gradient descent.
  • Loss functions including MSE and cross-entropy.
  • Overfitting/underfitting and regularization methods: L1, L2, dropout, batch normalization.
  • CNN components: convolution, pooling, and fully connected layers.
  • RNN basics with LSTM and GRU for sequence modeling.

Unit V: Model Evaluation and Validation (8 hrs)

  • Need for systematic model evaluation in ML.
  • Classification metrics: accuracy, precision, recall, F-beta score, confusion matrix, ROC, and PR curve.
  • Regression metrics: MAE, MSE, RMSE, and R-squared.
  • Validation methods: train-test split, cross-validation, and k-fold cross-validation.
  • Hyperparameter tuning via grid search and random search.

Important Topics

  • Workflow-driven ML problem framing.
  • Bias-variance and regularization in supervised learning.
  • Kernel selection in SVM-based models.
  • K-means and DBSCAN behavior on varying cluster shapes.
  • PCA/LDA for dimensionality reduction and visualization.
  • Loss-function choice and optimization dynamics.
  • CNN and RNN architecture use-cases.
  • Overfitting controls with dropout and normalization.
  • Metric selection for imbalanced classes.
  • Cross-validation and hyperparameter search strategy.

Practice Questions

  1. Design a complete ML workflow for a real dataset from preprocessing to deployment plan.
  2. Fit linear and ridge/lasso regression on a dataset and compare coefficient behavior and error metrics.
  3. Train at least two classification models (for example logistic regression and SVM) and compare ROC/PR performance.
  4. Apply k-means and DBSCAN on the same data and explain differences in resulting clusters.
  5. Use PCA to reduce dimensionality and evaluate how it affects downstream classification.
  6. Build a small MLP or CNN model and explain the effect of loss function and learning rate choices.
  7. Demonstrate overfitting and then reduce it using regularization, dropout, or early stopping.
  8. Run k-fold cross-validation with hyperparameter tuning and report the best model with justification.
