Introduction

Simulation and Modeling in Semester 6 develops the ability to represent real systems with mathematical and computational models before implementing costly real-world changes. In Pokhara University BE Computer Engineering, this subject builds a strong foundation for analytical experimentation by combining system concepts, model design, random process handling, and output interpretation. It is especially valuable when direct physical testing is expensive, risky, or time-consuming.

The course starts by clarifying system types and simulation workflow, then extends into Monte Carlo methods, queuing behavior, and time-advance mechanisms used in event-driven studies. It also covers continuous-system representation through differential equations and analog/digital/hybrid simulation perspectives. This blend of conceptual and computational modeling helps students evaluate behavior under varying assumptions.

Later units focus on discrete-event simulation languages, random-number generation/testing, and output analysis methods such as run statistics, replication, and initial-bias elimination. These units are crucial because simulation conclusions are only useful when statistical validity is maintained. With consistent model-building practice and result interpretation, students gain practical skills directly applicable to performance engineering, operations analysis, and research projects.

What you will learn

  • Define systems and classify them by behavior and uncertainty characteristics.
  • Design simulation studies using structured modeling steps and validation checks.
  • Apply Monte Carlo and queuing concepts for system-level performance analysis.
  • Represent and analyze continuous systems using differential-equation based models.
  • Model discrete-event systems and collect simulation statistics.
  • Generate pseudo-random numbers and test uniformity/independence.
  • Use discrete simulation languages and tools for implementation.
  • Perform output analysis and remove bias for reliable decision-making.

Syllabus Overview

Unit 1: Introduction to Simulation and Modeling (4 hrs)

  • System concepts and system environment.
  • Types of systems: continuous/discrete, static/dynamic, stochastic/deterministic.
  • Simulation steps and modeling principles.
  • Advantages, disadvantages, and applications of simulation.
  • Model verification and validation basics.

Unit 2: System Simulation (8 hrs)

  • Monte Carlo method and related numerical problems.
  • Simulation vs analytical solution comparison.
  • System simulation types and real-time simulation.
  • Lag models: distributed lag and cobweb model.
  • Queuing-system characteristics and notation.
  • Single-server queuing model with arrival/departure routines and performance measures.
  • Time-advance mechanisms: next-event and fixed-increment methods.

Unit 3: Continuous System (8 hrs)

  • Introduction to continuous systems.
  • Representation using differential equations.
  • Linear and nonlinear differential-equation models.
  • Analog computer concepts and examples.
  • Digital-analog simulators and hybrid computers.
  • CSSL/CSMP III statements: structural, data, and control.
  • Feedback and interactive-system examples.

Unit 4: Discrete System (7 hrs)

  • Discrete-system introduction and components.
  • Representation of time in discrete systems.
  • Examples: telephone call systems and bank-queue systems.
  • Simulation programming tasks and stepwise process.
  • Gathering statistics, counters, summary measures, utilization, and occupancy.
  • Recording distributions and summary measures.

Unit 5: Probability Concept and Random Numbers (7 hrs)

  • Stochastic systems and probability functions (discrete/continuous).
  • True random vs pseudo-random numbers.
  • Properties and generation techniques for random numbers.
  • Linear congruential, mixed, additive, and incremental generators.
  • Randomness tests: KS, chi-square, run tests, autocorrelation, gap, and poker tests.

Unit 6: Discrete System Languages (6 hrs)

  • Simulation using GPSS and related exercises.
  • Simulation using SIMSCRIPT and program organization.
  • Other discrete simulation languages overview.

Unit 7: Output Analysis Method (5 hrs)

  • Nature of output-analysis problems.
  • Estimation methods for simulation results.
  • Simulation run statistics.
  • Replication of runs.
  • Elimination of initial bias.

Important Topics

  • System classification and model abstraction quality.
  • Monte Carlo design and interpretation.
  • Single-server queue metrics and event scheduling.
  • Continuous vs discrete simulation assumptions.
  • Pseudo-random generator quality and test criteria.
  • KS and chi-square based uniformity verification.
  • Run/autocorrelation tests for independence.
  • GPSS and SIMSCRIPT usage patterns.
  • Replication strategy for confidence in outputs.
  • Initial-transient bias handling in simulation studies.

Practice Questions

  1. Model a real system of your choice and classify it as continuous/discrete and stochastic/deterministic with justification.
  2. Solve one Monte Carlo estimation problem and compare with an analytical result when available.
  3. Construct and analyze a single-server queue with clear arrival/departure assumptions.
  4. Represent a continuous process using differential equations and explain simulation assumptions.
  5. Generate pseudo-random numbers using one generator and test uniformity and independence.
  6. Prepare a short GPSS or SIMSCRIPT-style simulation design for a queuing or inventory scenario.
  7. Collect and summarize simulation-run statistics for repeated experiments.
  8. Demonstrate how to remove initial bias and report more reliable output estimates.
