Introduction

Compiler Design in Semester 6 is a theory-and-practice subject that explains how high-level programs are translated into executable machine-level instructions. In Pokhara University BE Computer Engineering, this course is structured around the complete compiler pipeline: lexical analysis, syntax analysis, intermediate representation, optimization, and code generation. It connects formal-language concepts with systems-level implementation, making it one of the most important subjects for understanding programming-language internals.

The early units focus on scanner and parser construction where regular expressions, finite automata, context-free grammars, LL parsing, and LR parsing are applied. Students learn both the mathematical basis and practical tool usage such as Lex/Yacc style workflows. This combination is valuable because compiler components require both formal correctness and engineering trade-off decisions.

The later units cover IR design, symbol tables, machine-independent optimization, data-flow analysis, and backend code generation strategies including register allocation and peephole optimization. These topics develop strong reasoning about runtime efficiency, memory behavior, and translation quality. Regular implementation practice with scanner/parser builders and control-flow problems makes this subject highly rewarding for systems programming and language-tooling careers.

What you will learn

  • Explain compiler structure and the role of front end, optimizer, and back end.
  • Construct lexical analyzers using regular expressions, NFA/DFA, and scanner-generator ideas.
  • Design top-down and bottom-up parsers for context-free grammars.
  • Build LL(1) and LR(1) parsing logic for language syntax analysis.
  • Use intermediate representations and symbol tables for translation.
  • Apply code generation fundamentals with flow graphs and basic-block optimization.
  • Use machine-independent optimization techniques such as constant propagation and redundancy elimination.
  • Interpret and solve basic data-flow analysis equations for optimization decisions.

Syllabus Overview

Unit I: Overview of Compilation (4 hrs)

  • Compiler vs interpreter and need of compilation.
  • Compiler structure and translation workflow.
  • Roles of front end, optimizer, and backend.
  • Programming-language basics from the compiler perspective.

Unit II: Scanners (7 hrs)

  • Role of lexical analyzer and token recognition.
  • Regular-expression formalization and closure properties.
  • Finite-automata based recognition.
  • Thompson construction: regular expression to NFA.
  • NFA to DFA conversion and DFA-based recognizer design.
  • Lexical-analyzer generators and optimization of DFA-based pattern matching.

Unit III: Parsers (6 hrs)

  • Syntax analyzer fundamentals and context-free grammars.
  • Top-down parsing and grammar transformation for LL parsing.
  • Recursive-descent parser and table-driven LL(1) parser.
  • Bottom-up parsing approach.
  • LR(1) parsing algorithm and LR(1) table construction.

Unit IV: Intermediate Representations (5 hrs)

  • Taxonomy of intermediate representations.
  • Graphical IRs: syntax-related trees and graphs.
  • Linear IR forms and value naming.
  • Symbol-table construction using hash tables.

Unit V: Code Generation (4 hrs)

  • Design issues in code generation.
  • Basic blocks and flow graphs.
  • Optimization of basic blocks.
  • Simple code generator and peephole optimization.
  • Register allocation and assignment strategies.
  • Dynamic-programming approach to code generation.

Unit VI: Machine Independent Optimization (4 hrs)

  • Principal sources of optimization.
  • Loop optimization in flow graphs.
  • Constant propagation and partial redundancy elimination.
  • Introduction to data-flow analysis.
  • Solving data-flow equations.

Important Topics

  • Front-end/back-end responsibilities in translation pipelines.
  • Regular expressions to NFA/DFA conversion workflow.
  • FIRST/FOLLOW and LL(1) parser construction basics.
  • LR parsing-table generation and conflict handling.
  • IR design choices for optimization-friendly compilers.
  • Hash-table based symbol-table operations.
  • Flow-graph and basic-block level transformations.
  • Register allocation impact on generated code quality.
  • Constant propagation and redundancy elimination effects.
  • Data-flow equation setup and solution interpretation.

Practice Questions

  1. Explain the full compiler pipeline and classify each phase into front end, optimizer, or back end.
  2. Convert a regular expression into NFA and DFA, then trace token recognition on sample inputs.
  3. Transform a grammar for LL(1) parsing and build its predictive parsing table.
  4. Construct a basic LR parsing table for a given grammar and show parsing steps.
  5. Design an intermediate representation for a small expression language and build related symbol-table entries.
  6. Split a sample code fragment into basic blocks, draw its control-flow graph, and perform one peephole optimization.
  7. Apply constant propagation and partial redundancy elimination on a small three-address code sequence.
  8. Formulate one data-flow problem (for example reaching definitions) and solve the equations iteratively.
