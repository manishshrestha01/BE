Introduction

Image Processing and Pattern Recognition in Semester 6 introduces the full pipeline of how machines read, enhance, analyze, and classify visual information. In Pokhara University BE Computer Engineering, this subject is designed to connect mathematical concepts, signal processing intuition, and practical computer vision workflows. Students begin with digital image basics, perception, sampling, and pixel relationships, then progressively move toward enhancement, restoration, compression, segmentation, and recognition tasks.

The middle units are highly practical because they train students to improve image quality in both spatial and frequency domains. Techniques such as histogram equalization, smoothing and sharpening filters, Fourier transforms, and noise removal methods are central for real-world imaging systems. The course also addresses compression and coding so students can reason about storage, bandwidth, and quality trade-offs. This is especially useful for multimedia systems, medical imaging, and networked visual applications.

The final units focus on image analysis and pattern recognition where feature extraction, segmentation, descriptors, and classifiers are combined into a complete decision-making flow. Topics such as PCA, SIFT, prototype matching, Bayes classification, and neural-network basics make this course a direct foundation for advanced AI and computer vision work. With regular lab implementation and method comparison, this subject becomes both conceptually strong and industry-relevant.

What you will learn

  • Explain core digital image processing concepts including sampling, quantization, and pixel relationships.
  • Apply spatial-domain enhancement methods such as point operations, histogram processing, and filtering.
  • Use Fourier-based frequency-domain techniques for smoothing and sharpening.
  • Model image degradation and apply restoration methods for common noise types.
  • Compare lossy and lossless compression approaches with entropy and coding concepts.
  • Perform image segmentation and region-based analysis for object extraction.
  • Use feature descriptors and dimensionality-reduction techniques for pattern tasks.
  • Apply pattern recognition methods including prototype matching, Bayes classifiers, and ANN fundamentals.

Syllabus Overview

Unit 1: Introduction to Digital Image Processing (4 hrs)

  • Fundamental steps and elements of digital image processing.
  • Application areas of DIP.
  • Visual perception, sampling, and quantization.
  • Image types: grayscale and color images.
  • Pixel relationships: neighbors, path, connectivity, adjacency, and distance.

Unit 2: Image Enhancement in Spatial Domain (7 hrs)

  • Gray-level transformations and point operations.
  • Contrast stretching, thresholding, digital negative, intensity-level slicing, and bit-plane slicing.
  • Histogram modeling, equalization, and matching.
  • Enhancement using arithmetic and logic operations.
  • Spatial filtering including smoothing and sharpening.
  • Averaging, median filtering, low-pass, high-pass, and interpolation-based magnification.

Unit 3: Image Enhancement in the Frequency Domain (6 hrs)

  • Introduction to Fourier transform, DFT, and FFT for images.
  • Computing and visualizing 2D DFT.
  • Frequency-domain smoothing filters.
  • Frequency-domain sharpening filters.
  • Other transforms: Hadamard, Haar, and discrete cosine transform.

Unit 4: Image Restoration (4 hrs)

  • Image degradation and restoration process model.
  • Restoration in the presence of noise using spatial filtering.
  • Noise models: white, salt-and-pepper, impulse, Gaussian, and Rayleigh.
  • Periodic noise reduction using frequency-domain filtering.

Unit 5: Image Compression and Coding (7 hrs)

  • Need of compression and compression issues.
  • Lossy and lossless compression concepts.
  • Generic compression model and information-theory basics (self-information, entropy).
  • Data redundancy and coding redundancy.
  • Entropy encoding: run-length, Huffman, and LZW coding.
  • Transform coding and predictive coding concepts.

Unit 6: Image Analysis (9 hrs)

  • Feature extraction and feature types.
  • Discontinuity-based segmentation: point, line, and edge detection.
  • Similarity-based segmentation and thresholding variants.
  • Amplitude, histogram-based, multi-level, local/global, and optimum thresholding.
  • Region-growing, region-splitting, and merging methods.
  • Region description and representation: chain code, polygon approximation, signatures, shape numbers, and Fourier descriptors.

Unit 7: Pattern Recognition and ANN in Pattern Recognition (8 hrs)

  • Image patterns and recognition pipeline.
  • General steps of pattern recognition.
  • Boundary preprocessing and boundary/region feature descriptors.
  • Feature extraction methods including PCA and SIFT.
  • Pattern and pattern-class concepts.
  • Prototype matching and Bayes statistical classification.
  • Artificial neural network basics with perceptron and Hopfield network.

Important Topics

  • Sampling-quantization effects on image quality.
  • Histogram equalization vs matching use-cases.
  • Spatial vs frequency-domain filtering trade-offs.
  • Noise model selection for restoration strategy.
  • Entropy and redundancy in compression design.
  • Thresholding and region-based segmentation comparison.
  • Descriptor quality for shape representation.
  • PCA and SIFT for robust feature extraction.
  • Bayes decision rule for pattern classes.
  • ANN use in pattern-recognition pipelines.

Practice Questions

  1. Explain the digital image processing pipeline and discuss how sampling and quantization influence reconstruction quality.
  2. Apply histogram equalization and a spatial filter to a sample image, then compare visual and numerical outcomes.
  3. Compute and interpret a 2D DFT-based enhancement for a noisy image.
  4. Choose a suitable restoration method for salt-and-pepper and Gaussian noise cases and justify your selection.
  5. Compare run-length, Huffman, and LZW coding with one short compression workflow.
  6. Implement one edge-based and one region-based segmentation method and compare extracted objects.
  7. Build a feature set using PCA or SIFT and discuss its effect on class separability.
  8. Design a basic pattern classifier using prototype matching or Bayes rule and evaluate performance.
